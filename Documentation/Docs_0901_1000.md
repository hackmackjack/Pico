## 1. Project 901: Advanced Weather Station Sensor Setup

### 2. Learning Objective
"Bus Scan". Setup BMP280 (I2C) and DHT11 (GPIO) simultaneously. Print status of both connections.

### 3. Concepts Introduced
*   **Multi-Sensor Interface**: Managing different protocols (I2C vs one-wire) in one script.
*   **Initialization Checks**: Ensuring hardware is ready before main loop.

### 4. Hardware Required
*   **Raspberry Pi Pico**
*   **BMP280 (I2C)**
*   **DHT11 (3-pin)**

### 5. Wiring / Interfaces
| Component | Pico Pin | Notes |
| :--- | :--- | :--- |
| **BMP280 SDA** | GP0 | I2C0 Data |
| **BMP280 SCL** | GP1 | I2C0 Clock |
| **DHT11 Data** | GP15 | Digital Pin (Pull-up recommended) |

### 6. Blocks Used
*   **from Smart Sensors, drag `read_dht`**
*   **from I2C, drag `init_i2c`**

### 7. Variables
*   **bmp_ready** (Boolean)
*   **dht_ready** (Boolean)

### 8. Step-by-Step Guide

**A. Initialization Phase**
1.  **Setup I2C Bus**:
    *   From **I2C**, drag `init_i2c`.
    *   Set SDA to **GP0**, SCL to **GP1**.
    *   Set frequency to **400000** Hz.
    *   Assign to variable `i2c`.
    *   **Snap** into `start`.
2.  **Scan for BMP280**:
    *   From **I2C**, drag `i2c_scan`.
    *   Check if address **0x76** or **0x77** is present.
    *   From **Smart Sensors**, drag `init_bmp280`.
    *   Pass `i2c` object.
    *   Assign to variable `bmp`.
3.  **Setup DHT11**:
    *   From **Smart Sensors**, drag `read_dht`.
    *   Set Pin to **GP15**.
    *   Set Type to **DHT11**.
    *   Assign to variable `sensor`.

**B. Verification Phase**
4.  **Test BMP280**:
    *   From **Try/Except**, drag `try_except` block.
    *   Inside Try: Read `bmp.pressure`.
    *   If success: Print "BMP280: OK".
    *   Inside Except: Print "BMP280: Error".
5.  **Test DHT11**:
    *   From **Try/Except**, drag `try_except` block.
    *   Inside Try: Call `sensor.measure()`.
    *   Read `sensor.temperature()`.
    *   Print "DHT11: OK + Temperature".
    *   Inside Except: Print "DHT11: Error".

### 9. Execution Flow
1.  **Boot**: "Initializing Sensors...".
2.  **Check**: "BMP found at 0x76".
3.  **Check**: "DHT read: 25C".
4.  **Result**: "Weather Station Online".

### 10. Generated Code
``python
import machine
import utime
import dht
from bmp280 import BMP280 # Assuming lib
from machine import I2C, Pin

# I2C Setup
i2c = I2C(0, sda=Pin(0), scl=Pin(1), freq=400000)
bmp = None

try:
    if 0x76 in i2c.scan():
        bmp = BMP280(i2c)
        print("BMP280: OK")
    else:
        print("BMP280: Not Found")
except:
    print("BMP280: Error")

# DHT Setup
sensor = dht.DHT11(Pin(15))

try:
    sensor.measure()
    print(f"DHT11: OK (T={sensor.temperature()})")
except:
    print("DHT11: Error")
    
utime.sleep(1)
``

### 11. Common Mistakes
*   **Address Conflict**: Some BMP280s are 0x77.
*   **DHT11 Timing**: Needs 1s between reads or it fails.

### 12. Try This Next
*   **LCD**: Display "Init OK" on screen.

## 1. Project 903: Advanced Weather Station Threshold Logic

### 2. Learning Objective
"Storm Alert". If Pressure drops > 2 hPa in 1 hour -> "Storm Warning".
(Accelerated for demo: > 2hPa in 10s).

### 3. Concepts Introduced
*   **Trend Analysis**: Comparing current value to historical value.
*   **Rate of Change**: dP/dt.

### 4. Hardware Required
*   **Raspberry Pi Pico**
*   **BMP280**
*   **Red LED**

### 5. Wiring / Interfaces
| Component | Pico Pin | Notes |
| :--- | :--- | :--- |
| **BMP280 SDA** | GP0 | I2C0 Data |
| **BMP280 SCL** | GP1 | I2C0 Clock |
| **Red LED** | GP14 | Storm warning indicator |

### 6. Blocks Used
*   **from Logic, drag `if`**

### 7. Variables
*   **last_pressure** (Number)

### 8. Step-by-Step Guide

**A. Initialization Phase**
1.  **Setup LED**:
        *   Set Pin to **GP14**, Mode to **Output**.
    *   Assign to variable `led`.
2.  **First Reading**:
    *   From **Smart Sensors**, drag `read_sensor`.
    *   Read BMP280 Pressure, divide by 100.
    *   Assign to variable `last_pressure`.

**B. Main Loop Phase**
3.  **Wait Interval**:
    *   From **Smart IO**, drag `pico_wait`. Set to **5 seconds** (demo interval).
4.  **Read Current Pressure**:
    *   From **Smart Sensors**, drag `read_sensor`.
    *   Read BMP280 Pressure, divide by 100.
    *   Assign to variable `curr_pressure`.
5.  **Calculate Difference**:
    *   From **Math**, drag `subtract`.
    *   Calculate `last_pressure - curr_pressure`.
    *   Assign to variable `diff`.
6.  **Check Threshold**:
    *   From **Logic**, drag `controls_if`.
    *   Condition: If `diff > 1.0` (1 hPa drop).
    *   From **Smart IO**, drag `pico_gpio_write`. Set `led` to **HIGH**.
    *   Print "STORM WARNING".
7.  **Update Reference**:
    *   From **Variables**, drag `variables_set`.
    *   Set `last_pressure` to `curr_pressure`.

### 9. Execution Flow
1.  **Stable**: 1013 -> 1013. Quiet.
2.  **Drop**: User sucks on sensor tube (simulating low pressure). 1013 -> 1000.
3.  **Alert**: LED Flashes "STORM!".

### 10. Generated Code
``python
last_p = bmp.pressure / 100
led = machine.Pin(14, machine.Pin.OUT)

print(f"Reference: {last_p:.1f} hPa")

while True:
    utime.sleep(5)
    curr_p = bmp.pressure / 100
    diff = last_p - curr_p
    
    if diff > 1.0: # 1 hPa drop (Sensitive for demo)
        print(f"DROP DETECTED! -{diff:.1f} hPa")
        led.value(1)
    else:
        led.value(0)
    
    last_p = curr_p # Moving reference
``

### 11. Common Mistakes
*   **noise**: Small fluctuations (0.1 hPa) are normal. Need a threshold of at least 1-2 hPa.

### 12. Try This Next
*   **Rising**: If pressure rises fast, "Clear Skies".

## 1. Project 905: Automated Advanced Weather Station Controller

### 2. Learning Objective
"Rain Gauge Wiper". If Rain Sensor (ADC) > value (Wet), Servo wipes the sensor surface (Windshield wiper logic).

### 3. Concepts Introduced
*   **Actuation**: Physical response to weather.
*   **Conditioning**: Analog value -> Motor action.

### 4. Hardware Required
*   **Raspberry Pi Pico**
*   **Rain Sensor (Analog)**
*   **Servo**

### 5. Wiring / Interfaces
| Component | Pico Pin | Notes |
| :--- | :--- | :--- |
| **Rain Sensor Analog Out** | GP26 | ADC0 |
| **Servo Signal** | GP0 | PWM capable |

### 6. Blocks Used
*   **from Motion & Motors, drag `move_servo`**

### 7. Variables
*   **rain_val** (Number)

### 8. Step-by-Step Guide

**A. Initialization Phase**
1.  **Setup Rain Sensor**:
    *   From **Smart IO**, drag `pico_read_analog`.
    *   Set Pin to **GP26** (ADC0).
2.  **Setup Servo**:
    *   From **Motion & Motors**, drag `servo_setup`.
    *   Set Pin to **GP0**.
    *   Assign to variable `servo`.

**B. Main Loop Phase**
3.  **Read Rain Level**:
    *   From **Smart IO**, drag `pico_read_analog`.
    *   Read from **GP26**.
    *   Assign to variable `rain_val`.
4.  **Check Wet Condition**:
    *   From **Logic**, drag `controls_if`.
    *   Condition: If `rain_val < 20000` (Wet threshold).
5.  **Wiper Sequence**:
    *   From **Motion & Motors**, drag `move_servo`. Set servo to **0°**.
    *   From **Smart IO**, drag `pico_wait`. Set to **0.5 seconds**.
    *   From **Motion & Motors**, drag `move_servo`. Set servo to **180°**.
    *   From **Smart IO**, drag `pico_wait`. Set to **0.5 seconds**.
    *   From **Motion & Motors**, drag `move_servo`. Set servo to **0°** (return).
    *   From **Smart IO**, drag `pico_wait`. Set to **1 second**.

### 9. Execution Flow
1.  **Dry**: System idle.
2.  **Splosh**: Water on sensor. ADC drops.
3.  **Action**: Servo *Swish Swish*.

### 10. Generated Code
``python
rain = machine.ADC(26)
servo = machine.PWM(machine.Pin(0))
servo.freq(50)

def set_angle(a):
    d = int(1000 + (a/180)*8000)
    servo.duty_u16(d)

while True:
    val = rain.read_u16()
    print(val)
    
    if val < 20000: # Very Wet
        print("Wiping...")
        set_angle(0)
        utime.sleep(0.5)
        set_angle(180)
        utime.sleep(0.5)
        set_angle(0)
        utime.sleep(1) # Wait before next wipe
    
    utime.sleep(0.5)
``

### 11. Common Mistakes
*   **Power**: Don't run servo from 3V3 if under load.
*   **Corrosion**: Rain sensors corrode fast in real water. Gold plating helps.

### 12. Try This Next
*   **Count**: Count how many wipes (proxy for total rainfall?).

## 1. Project 906: Advanced Weather Station Safety Trigger

### 2. Learning Objective
"Freeze Protect". If Temp < 4C, turn on "Heater" (LED) to prevent frost damage to crops.

### 3. Concepts Introduced
*   **Hysteresis**: Turn on at 4C, turn off at 6C (prevent rapid toggling).
*   **Critical Thresholds**: Agriculture needs.

### 4. Hardware Required
*   **Raspberry Pi Pico**
*   **Temp Sensor**
*   **LED**

### 5. Wiring / Interfaces
| Component | Pico Pin | Notes |
| :--- | :--- | :--- |
| **DHT11 Data** | GP15 | Or use internal temp sensor |
| **LED (Heater indicator)** | GP14 | Output |

### 6. Blocks Used
*   **from Logic, drag `if_else`**

### 7. Variables
*   **heater_on** (Boolean)

### 8. Step-by-Step Guide

**A. Initialization Phase**
1.  **Setup Heater LED**:
        *   Set Pin to **GP14**, Mode to **Output**.
    *   Assign to variable `heater`.
2.  **Setup Temperature Sensor**:
    *   From **Smart Sensors**, drag `read_dht` or use internal sensor.

**B. Main Loop Phase**
3.  **Read Temperature**:
    *   From **Smart Sensors**, drag `read_sensor`.
    *   Get current temperature.
    *   Assign to variable `temp`.
4.  **Hysteresis Logic**:
    *   From **Logic**, drag `controls_if` with else-if.
    *   If `temp < 4`: From **Smart IO**, drag `pico_gpio_write`. Set `heater` to **HIGH**.
    *   Else if `temp > 6`: From **Smart IO**, drag `pico_gpio_write`. Set `heater` to **LOW**.
    *   (Between 4-6: No change - hysteresis band).
5.  **Wait**:
    *   From **Smart IO**, drag `pico_wait`. Set to **1 second**.

### 9. Execution Flow
1.  **Night**: Temp drops. 5C... 4C... 3.9C.
2.  **Action**: "FROST WARNING". Heater On.
3.  **Day**: Temp rises. 5C... 6.1C. Heater Off.

### 10. Generated Code
``python
heater = machine.Pin(15, machine.Pin.OUT)

while True:
    sensor.measure()
    t = sensor.temperature()
    
    if t < 4:
        heater.value(1)
        print("Heater: ON (Frost Risk)")
    elif t > 6:
        heater.value(0)
        print("Heater: OFF")
        
    utime.sleep(1)
``

### 11. Common Mistakes
*   **Placement**: Don't place sensor near the heater, or it will turn off immediately (Short cycle).

### 12. Try This Next
*   **Alarm**: Add buzzer if Temp < 0C (Critical Freeze).

## 1. Project 909: Advanced Weather Station Calibration Tool

"Altitude Offset". BMP280 gives Absolute Pressure. To get Relative (Sea Level) pressure, user must input current Altitude in meters.

### 3. Concepts Introduced

*   **Wait for Input**: Interactive setup.

### 4. Hardware Required
*   **Raspberry Pi Pico**
*   **BMP280**
*   **Console Input**

### 5. Wiring / Interfaces
| Component | Pico Pin | Notes |
| :--- | :--- | :--- |

| **BMP280 SCL** | GP1 | I2C0 |

### 6. Blocks Used
*   **from Sensing, drag `ask_text`**

### 7. Variables
*   **alt_m** (Number)

### 8. Step-by-Step Guide

**A. Setup Phase**
1.  **Read Absolute Pressure**:
    *   From **Smart Sensors**, drag `read_sensor`.
    *   Read BMP280 pressure, divide by 100.
    *   Assign to variable `p_abs`.
    *   Print current reading.
2.  **Get User Input**:
    *   From **Text**, drag `input`.
    *   Prompt: "Enter Station Height (m): ".
    *   Assign to variable `height_m`.
3.  **Calculate Correction**:
    *   From **Math**, drag `divide`.
    *   Calculate `correction = height_m / 8.3` (approx 1hPa per 8.3m).
4.  **Calculate Sea Level Pressure**:
    *   From **Math**, drag `add`.
    *   Calculate `p_sea = p_abs + correction`.
5.  **Display Result**:
    *   From **Text**, drag `print`.
    *   Print `"Sea Level Pressure: {p_sea} hPa"`.

### 9. Execution Flow
1.  **User**: Enters "100" (meters).

3.  **Output**: "Sea Level Pressure: 1012 hPa".

### 10. Generated Code
``python
p_abs = bmp.pressure / 100

print(f"Absolute Pressure: {p_abs:.2f}")

h_str = input("Enter Station Height (m): ")
h = float(h_str)

# Substraction formula derived from hypsometric equation
# Approx: Pressure drops ~1hPa per 8.3m
correction = h / 8.3
p_sea = p_abs + correction

print(f"Corrected (Sea Level): {p_sea:.2f} hPa")
``

### 11. Common Mistakes
*   **Formula**: The 8.3m/hPa rule is an approximation near sea level. The real formula uses exponents.

### 12. Try This Next

## 1. Project 960: Advanced Advanced Temp/Humidity (DHT) Prototype

### 2. Learning Objective
"Psychrometric Calc". Calculate Absolute Humidity (g/m^3) from Relative Humidity and Temp.

### 3. Concepts Introduced
*   **Thermodynamics**: Saturation Vapor Pressure.
*   **Complex Math**: Exponents and constants.

### 4. Hardware Required
*   **Raspberry Pi Pico**
*   **DHT11**

### 5. Wiring / Interfaces
| Component | Pico Pin | Notes |
| :--- | :--- | :--- |
| **DHT11** | GP15 | Sensor |

### 6. Blocks Used
*   **from Math, drag `exp`**

### 7. Variables
*   **abs_hum**

### 8. Step-by-Step Guide

**A. Psychrometric Formula**
1.  **Get Data**:
    *   Read `T` and `H`.
2.  **Calculate SVP (Saturation Vapor Pressure)**:
    *   `SVP = 6.112 * exp((17.67 * T) / (T + 243.5))`.
3.  **Calculate Absolute Humidity**:
    *   `VP = SVP * H / 100`.
    *   `AH = (VP * 216.7) / (T + 273.15)`.
4.  **Output**:
    *   Print `AH` + " g/m^3".

### 9. Execution Flow
1.  **Input**: 25C, 50%.
2.  **Result**: "11.5 grams of water per cubic meter".

### 10. Generated Code
``python
import math

while True:
    d.measure()
    t = d.temperature()
    h = d.humidity()
    
    # Magnus formula
    # Saturation Vapor Pressure (hPa)
    es = 6.112 * math.exp((17.67 * t) / (t + 243.5))
    
    # Actual Vapor Pressure
    e = es * (h / 100.0)
    
    # Absolute Humidity (g/m^3)
    ah = (e * 216.7) / (t + 273.15)
    
    print(f"Abs Hum: {ah:.2f} g/m^3")
    utime.sleep(2)
``
