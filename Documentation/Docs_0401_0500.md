### 9. Execution Flow

LED A toggles every 0.5 seconds (on for 0.5s, off for 0.5s = 1Hz). LED B toggles every 0.25 seconds (2Hz). Initially, they might align, but quickly drift. Every 2 seconds they realign (since 1Hz × 2 = 2Hz × 1). This demonstrates how different frequencies create complex interference patterns, similar to musical polyrhythms.

### 10. Generated Code

``python
import machine
import time

ledA = machine.Pin(16, machine.Pin.OUT)
ledB = machine.Pin(17, machine.Pin.OUT)

stateA = False
stateB = False
last_toggle_a = time.time()
last_toggle_b = time.time()

while True:
    current_time = time.time()
    
    # LED A: 1Hz (toggle every 0.5s)
    if current_time - last_toggle_a >= 0.5:
        stateA = not stateA
        ledA.value(stateA)
        last_toggle_a = current_time
    
    # LED B: 2Hz (toggle every 0.25s)
    if current_time - last_toggle_b >= 0.25:
        stateB = not stateB
        ledB.value(stateB)
        last_toggle_b = current_time
    
    time.sleep(0.01)
``

### 11. Common Mistakes

*   **Both LEDs Same Speed**: Verify the toggle intervals (0.5s vs 0.25s) are different.
*   **Timing Drift**: Using `sleep()` alone causes drift. Use timestamp-based toggling as shown.

### 12. Try This Next

*   **3:2 Polyrhythm**: Make LED A blink at 1Hz and LED B at 1.5Hz for a different pattern.
*   **Visual Metronome**: Add a third LED blinking at 0.5Hz (downbeat) to create a rhythmic reference.

### 9. Execution Flow

Button A controls LED A momentarily: hold button → LED on, release → LED off. Button B controls LED B with latching: first press → LED on (stays on), second press → LED off (stays off). The key difference is state retention. Momentary switches require continuous pressure; latching switches remember their state.

### 10. Generated Code

``python
import machine
import time

buttonA = machine.Pin(14, machine.Pin.IN, machine.Pin.PULL_DOWN)
buttonB = machine.Pin(15, machine.Pin.IN, machine.Pin.PULL_DOWN)
ledA = machine.Pin(16, machine.Pin.OUT)
ledB = machine.Pin(17, machine.Pin.OUT)

latch_state = False
last_button_b = False

while True:
    # Momentary LED A
    ledA.value(buttonA.value())
    
    # Latching LED B
    current_button_b = buttonB.value()
    if current_button_b and not last_button_b:  # Rising edge
        latch_state = not latch_state
        ledB.value(latch_state)
    last_button_b = current_button_b
    
    time.sleep(0.05)
``

### 11. Common Mistakes

*   **Latching Skips**: Without edge detection, holding the button toggles rapidly. Ensure you check `not lastButtonB`.
*   **No Debounce**: Cheap buttons may double-toggle. Add 0.2s delay after toggle if needed.

*   **Multi-Tap**: Make button B require a double-click to toggle (prevents accidental presses).

### 10. Generated Code

``python
import machine
import time

current_led = 0
direction = 1

while True:
    # Turn off all LEDs
    for led in leds:
        led.off()
    
    # Light current LED
    leds[current_led].on()
    
    # Move to next position
    current_led += direction
    
    # Reverse at boundaries
    if current_led == 4:
        direction = -1
    elif current_led == 0:
        direction = 1
    
    time.sleep(0.2)
``

### 11. Common Mistakes

*   **Out of Bounds**: If you check boundaries after incrementing, you might get index 5 (invalid). Check *at* the endpoints (0 and 4), not after.
*   **Stuck at End**: Ensure direction changes to -1 at 4 and +1 at 0.

### 9. Execution Flow

### 10. Generated Code

``python
import machine
import time

pot = machine.ADC(26)
led = machine.PWM(machine.Pin(16))
led.freq(1000)

while True:
    pot_value = pot.read_u16()
    percentage = (pot_value / 65535) * 100
    
    if percentage < 20:
        # Mode 0: Off
        led.duty_u16(0)
    elif percentage < 40:
        # Mode 1: Solid On
        led.duty_u16(65535)
    elif percentage < 60:
        # Mode 2: Slow Blink
        led.duty_u16(65535)
        time.sleep(1)
        led.duty_u16(0)
        time.sleep(1)
    elif percentage < 80:
        # Mode 3: Fast Blink
        led.duty_u16(65535)
        time.sleep(0.2)
        led.duty_u16(0)
        time.sleep(0.2)
    else:
        # Mode 4: Strobe
        led.duty_u16(65535)
        time.sleep(0.05)
        led.duty_u16(0)
        time.sleep(0.05)
``

### 11. Common Mistakes

*   **Mode Flicker**: If pot is near a boundary (e.g., 39%), it might flicker between modes. Add hysteresis (e.g., switch at 38% down, 42% up).
*   **Blocking Sleep**: Slow/Fast blink modes block other code. For non-blocking, use timestamp-based toggling.

        *   From **Smart IO**, drag `set PWM duty cycle pin:[16] to [brightness]`.
            *   **Snap** below.
    *   from **Smart IO**, drag `pico_wait`. Set to 0.1 seconds`.
        *   **Snap** below.

### 9. Execution Flow

The ultrasonic sensor measures distance to the nearest object (e.g., your hand). When your hand is 30cm away, the LED is at 0% brightness (off). As you move your hand closer, brightness increases linearly. At 5cm, the LED is at 100% brightness. This creates an interactive dimmer controlled by proximity, useful for touchless control.

### 10. Generated Code

``python
import machine
import time

trigger = machine.Pin(14, machine.Pin.OUT)
echo = machine.Pin(15, machine.Pin.IN)
led = machine.PWM(machine.Pin(16))
led.freq(1000)

def read_distance():
    trigger.low()
    time.sleep_us(2)
    trigger.high()
    time.sleep_us(10)
    trigger.low()
    
    while echo.value() == 0:
        pulse_start = time.ticks_us()
    while echo.value() == 1:
        pulse_end = time.ticks_us()
    
    pulse_duration = time.ticks_diff(pulse_end, pulse_start)
    distance = pulse_duration * 0.034 / 2
    return distance

while True:
    distance = read_distance()
    distance = max(5, min(30, distance))  # Clamp
    
    # Invert mapping: 30cm=0%, 5cm=100%
    brightness = int((30 - distance) / 25 * 65535)
    
    led.duty_u16(brightness)
    time.sleep(0.1)
``

### 11. Common Mistakes

*   **Wrong Brightness Direction**: If LED gets dimmer when closer, you mapped forward instead of inverted. Use `(30 - distance)` not `distance`.
*   **Flickering**: Ultrasonic readings can be noisy. Average the last 3 readings for stability.

### 12. Try This Next

*   **Exponential Response**: Use `brightness = (30 - distance)²` for more dramatic dimming near the sensor.
*   **Color Shift**: Use RGB LED—close = red, far = blue (heatmap effect).

        pinC.init(machine.Pin.IN)

        pinC.init(machine.Pin.OUT); pinC.off()
        pinB.init(machine.Pin.IN)

        pinC.init(machine.Pin.OUT); pinC.on()
        pinA.init(machine.Pin.OUT); pinA.off()
        pinB.init(machine.Pin.IN)

        pinC.init(machine.Pin.OUT); pinC.off()

### 9. Execution Flow

    current_time = time.time()
    
    # Raw edge detection
    if current_button and not last_button:
        raw_edge_count += 1
        
        # Debounced detection (50ms minimum between clicks)
        if current_time - last_edge_time > 0.05:
            debounced_click_count += 1
        
        last_edge_time = current_time

    time.sleep(0.001)

``python
import machine
import time

a_green = machine.Pin(16, machine.Pin.OUT)
a_red = machine.Pin(17, machine.Pin.OUT)

b_red = machine.Pin(19, machine.Pin.OUT)

current_side = 'A'

while True:
    if current_side == 'A':
        a_green.on()
        a_red.off()
        b_green.off()
        b_red.on()
    else:
        a_green.off()
        a_red.on()
        b_green.on()
        b_red.off()
    
    time.sleep(10)
    current_side = 'B' if current_side == 'A' else 'A'
