**Solution:**
``python
import _thread
import time

class ThreadWorker:
    def __init__(self):
        self.running = False
        self.active = False
        
    def _task(self):
        self.active = True
        while self.running:
            print("Worker doing work...")
            time.sleep(1)
        self.active = False
        print("Worker stopped.")

    def start(self):
        if not self.active:
            self.running = True
            _thread.start_new_thread(self._task, ())
            
    def stop(self):
        self.running = False
        
    def status(self):
        return "Running" if self.active else "Stopped"

class Encoder:
    def __init__(self, pinA, pinB):
        self.a = Pin(pinA, Pin.IN, Pin.PULL_UP)
        self.b = Pin(pinB, Pin.IN, Pin.PULL_UP)
        self.pos = 0
        self.a.irq(trigger=Pin.IRQ_RISING | Pin.IRQ_FALLING, handler=self._isr)
        
    def _isr(self, pin):
        # Quadrature logic simplified
        if self.a.value() == self.b.value():
            self.pos += 1
        else:
            self.pos -= 1
``

### Project 1693: Object-Oriented Professional PID Speed Control Class
**Category:** Motors & Motion
**Difficulty:** 8
**Bloom's:** Create

**Problem Statement:**
"PID Class". `pid = PID(kp, ki, kd)`. `output = pid.compute(input)`.

**Hardware Requirements:**
*   Pico

**Expected Behavior:**
*   Reusable component.

**Solution:**
``python
class PID:
    def __init__(self, kp, ki, kd):
        self.kp = kp
        self.ki = ki
        self.kd = kd
        self.prev_error = 0
        self.integral = 0
        
    def compute(self, error):
        self.integral += error
        derivative = error - self.prev_error
        self.prev_error = error
        return (self.kp*error) + (self.ki*self.integral) + (self.kd*derivative)
``
