## 1️⃣ Project 0101: Setup I2C & LCD Hello World

### 2️⃣ Learning Objective
Learn to use an I2C Display. Unlike an LED which only has ON/OFF, a display can show words and numbers. You will wire up a 16x2 Green LCD and make it say "Hello World".

### 3️⃣ Concepts Introduced
*   **I2C (Inter-Integrated Circuit)**: A protocol that allows speaking to complex devices using only 2 wires (SDA & SCL).
*   **Libraries**: Pre-written code that handles the hard work of sending bits to the screen.

### 4️⃣ Hardware Required
*   **Pico**
*   **16x2 LCD with I2C Backpack** (4 pins)
*   **Jumper Wires** (Female-to-Male usually)

### 5️⃣ Wiring / Interfaces
| Component | Pico Pin | Notes |
| :--- | :--- | :--- |
| **GND** | GND | Ground |
| **VCC** | VBUS (5V) | LCDs usually need 5V |
| **SDA** | GP0 | Serial Data |
| **SCL** | GP1 | Serial Clock |

### 6️⃣ Blocks Used
🔹 **Init I2C LCD**
*   **Category:** Displays
*   **Block:** `Initialize LCD Address [0x27]`
🔹 **Show Text**
*   **Category:** Displays
*   **Block:** `LCD Print [Hello World] at X:[0] Y:[0]`

### 7️⃣ Variables & State
*   None.

### 8️⃣ Step-by-Step Guide
*   **1. Setup**
    *   From **Displays**, drag `Initialize LCD Address [0x27]` into the `start` (or setup) block.
    *   *Note: Most LCDs are 0x27. If yours doesn't work, try 0x3F.*
*   **2. Main Loop**
    *   From **Displays**, drag `LCD Print [ "Hello World" ] at X:0 Y:0`.
    *   Snap it into the loop.

### 9️⃣ Execution Flow (Plain English)
The Pico wakes up and sends a "Wake Up" command to the screen address 0x27. Then it sends the letters H-e-l-l-o... to the screen memory. The screen lights up and shows the text.

### 🔟 Generated Code (Reference Only)
```python
import machine
from machine import I2C
from lcd_api import LcdApi
from i2c_lcd import I2cLcd

# I2C Setup
i2c = I2C(0, sda=machine.Pin(0), scl=machine.Pin(1), freq=400000)
lcd = I2cLcd(i2c, 0x27, 2, 16) # Address, Rows, Cols

while True:
    lcd.putstr("Hello World")
```

### 1️⃣1️⃣ Common Mistakes & Debug Tips
*   **Blue Box**: If you see blocks but no text, adjust the **Potentiometer** (blue knob) on the back of the screen with a screwdriver. It controls contrast.
*   **No Light**: Check VCC. It usually needs 5V (VBUS), not 3.3V.

### 1️⃣2️⃣ Try This Next
*   **Name Tag**: Change the text to show your name.

## 1️⃣ Project 0110: Mastering LCD (Optimization)

### 2️⃣ Learning Objective
Ensure the LCD updates smoothly without freezing the processor.

### 3️⃣ Concepts Introduced
*   **Non-Blocking Updates**: Updating only every 500ms, not every loop cycle.

### 4️⃣ Hardware Required
*   **Pico**
*   **LCD**

### 5️⃣ Wiring / Interfaces
*(Standard Setup)*

### 6️⃣ Blocks Used
🔹 **Time (Milliseconds)**
🔹 **If**

### 7️⃣ Variables & State
*   **last_update_time**

### 8️⃣ Step-by-Step Guide
*   **1. Setup Variables**
    *   `last_update_time` = 0.
*   **2. Loop**
    *   (Do other fast things here, like check buttons).
    *   IF (Current Time - `last_update_time`) > 500:
        *   Update LCD (Print Time/Data).
        *   `last_update_time` = Current Time.

### 9️⃣ Execution Flow (Plain English)
The Pico runs at million times a second. We don't need to write to the slow screen that often. We only write if 0.5 seconds have passed since the last write. The rest of the time, we are free to check for button presses instantly.

### 🔟 Generated Code (Reference Only)
```python
last_update = 0
while True:
    now = time.ticks_ms()
    if time.ticks_diff(now, last_update) > 500:
        lcd.move_to(0,0)
        lcd.putstr(str(now))
        last_update = now
    
    # Check buttons here (Instant response!)
```

### 1️⃣1️⃣ Common Mistakes & Debug Tips
*   **Why?**: If you write to the LCD too fast (every loop), the screen will blur and the Pico will spend all its time talking I2C.

### 1️⃣2️⃣ Try This Next
*   **Dual Task**: Blink an LED fast (10Hz) while updating the screen slow (1Hz).

### 3️⃣ Concepts Introduced

### 4️⃣ Hardware Required
*   **Pico**
*   **Pot**

### 5️⃣ Wiring / Interfaces
*(Standard Pot setup)*

### 6️⃣ Blocks Used
🔹 **Repeat**
🔹 **Math (Add, Divide)**

### 7️⃣ Variables & State
*   **total**, **average**

### 8️⃣ Step-by-Step Guide
*   **1. Loop**
    *   Set `total` = 0.
    *   **Inner Loop (10 times)**:
        *   `reading` = Read Pot.
        *   `total` = `total` + `reading`.
        *   Wait 0.001s.
    *   `average` = `total` / 10.
    *   Print `average`.

### 9️⃣ Execution Flow (Plain English)
Instead of trusting one single measurement (which might be wrong due to electrical noise), we take 10 quick snapshots and find the middle ground. The output is much smoother and stable.

### 🔟 Generated Code (Reference Only)
```python
while True:
    total = 0
    for i in range(10):
        total += adc.read_u16()
        time.sleep(0.001)
    
    avg = total // 10
    print(avg)
```

### 1️⃣1️⃣ Common Mistakes & Debug Tips
*   **Overflow**: If you add too many big numbers (like 1000 measurements), the variable might get too big for a small microcontroller to handle (though Python handles big integers well, C++ does not).

### 1️⃣2️⃣ Try This Next
*   **Weighted Average**: NewValue = (OldValue * 0.9) + (NewSample * 0.1). This is a "Low Pass Filter".
