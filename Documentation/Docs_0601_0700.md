``python

    time.sleep(0.5)

    blink_fast()
    blink_fast()
    blink_slow()
``

*   **Name Collision**: Function definitions must happen before they are called.

import machine, time
mic = machine.ADC(26)
leds = [machine.Pin(i, machine.Pin.OUT) for i in range(16, 19)]

        for l in leds: l.value(1)

## 6. Project 0606: Smart LED Patterns Switch

### 2. Learning Objective
Implement an energy-saving light that turns on via button and stays on if motion is detected, otherwise turning off after 10s.

### 3. Concepts Introduced
*   **Timer Reset**
*   **Sensor Fusion**
*   **State Maintenance**
*   **Energy Efficiency**

### 4. Hardware Required
*   **Pico**
*   **Button**
*   **PIR Sensor**
*   **LED**

### 5. Wiring / Interfaces
| **Button** | GP14 | Trigger |
| **PIR** | GP15 | Keep-Alive |
| **LED** | GP16 | Output |

### 6. Blocks Used
*   **from Smart IO, drag `time_ticks_ms`**
*   **from Logic, drag `if_do`**
*   **from Smart IO, drag `pico_gpio_read`**

### 7. Variables
*   ****expiryTime**: Time when light should turn off**

### 8. Step-by-Step Guide
**A. Initialization Phase**
1.  **Vars**:
  *   Set `expiryTime` to 0.

**B. Main Loop Phase**
1.  **Inputs**:
  *   From **Loops**, drag `pico_forever`.
  *   If Button (GP14) OR PIR (GP15):
      *   Set `expiryTime` to `current_time` + 10000.
  *   **Snap** into loop.
2.  **Logic**:
  *   If `current_time` < `expiryTime`:
      *   Turn LED On.
  *   Else:
      *   Turn LED Off.
  *   **Snap** below inputs.

### 9. Execution Flow
Instead of `sleep(10)`, we use a deadline approach. Any activity 'pushes back' the deadline. If the deadlines passes (current time > expiry), the light turns off.

### 10. Generated Code
``python
import machine, time
btn = machine.Pin(14, machine.Pin.IN, machine.Pin.PULL_DOWN)
pir = machine.Pin(15, machine.Pin.IN, machine.Pin.PULL_DOWN)
led = machine.Pin(16, machine.Pin.OUT)
expiry = 0

while True:
    if btn.value() or pir.value():
        expiry = time.ticks_add(time.ticks_ms(), 10000) # +10s
        
    if time.ticks_diff(expiry, time.ticks_ms()) > 0:
        led.value(1)
    else:
        led.value(0)
    time.sleep(0.1)
``

### 11. Common Mistakes
*   **PIR Delay**: PIR sensors have a hardware delay (potentiometer). Keep it minimum.
*   **Sleep**: Don't use `time.sleep(10)` or you can't detect motion during the wait.

### 12. Try This Next
*   **Fade Out**: PWM fade out when timer expires.
*   **Warning**: Blink briefly before turning off.

Create a reaction game where a random LED lights up and the player must press the corresponding button within 1 second.

### 3. Concepts Introduced

*   **Input Mapping**

### 4. Hardware Required
*   **Pico**
*   **3 LEDs**

### 5. Wiring / Interfaces
| **LEDs** | GP16-18 |
| **Btns** | GP13-15 |

### 6. Blocks Used
*   **from Math, drag `random_integer`**
*   **from Smart IO, drag `time_ticks_ms`**
*   **from Logic, drag `break_loop`**

### 7. Variables
*   ****score**: Integer**
*   ****target**: 0-2**

### 8. Step-by-Step Guide
**A. Initialization Phase**
1.  **Vars**:
  *   From **Variables**, set `score` to 0.
  *   **Snap** into setup block.

**B. Main Loop Phase**
1.  **New Round**:
  *   From **Loops**, drag `pico_forever`.
  *   From **Math**, set `target` to Random Integer (0, 2).
  *   **Snap** into loop.
2.  **Smart Display**:
  *   From **Smart IO**, turn Pin `target` + 16 (LED) ON.
  *   **Snap** below target selection.
3.  **Wait Input**:
  *   from **Smart IO**, set `start` to `time_ticks_ms`.
  *   From **Loops**, loop while `time_ticks_diff(time_ticks_ms, start) < 1000`:
      *   From **Logic**, if Button[`target`] pressed:
           *   Change `score` by 1.
           *   **Snap** (Break Loop).
      *   From **Logic**, if Wrong Button pressed:
           *   **Snap** (End Game).
  *   **Snap** below display.
4.  **Cleanup**:
  *   From **Smart IO**, turn Pin `target` + 16 OFF.
  *   from **Smart IO**, wait Random(0.5, 1.5).
  *   **Snap** at end of loop.

### 9. Execution Flow
The Code picks a target, starts a stopwatch, and watches inputs. Success resets the cycle. Failure (Wrong/Slow) ends the game.

### 10. Generated Code
``python
import machine, time, random
leds = [machine.Pin(i, machine.Pin.OUT) for i in range(16, 19)]
btns = [machine.Pin(i, machine.Pin.IN, machine.Pin.PULL_DOWN) for i in range(13, 16)]
score = 0

print("START!")
while True:
    target = random.randint(0, 2)
    leds[target].on()
    start = time.ticks_ms()
    hit = False
    
    while time.ticks_diff(time.ticks_ms(), start) < 1000:
        if btns[target].value():
            score += 1
            print(f"HIT! Score: {score}")
            hit = True
            break
        # Check wrong buttons
        for i in range(3):
            if i != target and btns[i].value():
                 print("WRONG!"); hit = False; start = 0 # Force fail
    
    leds[target].off()
    
    if not hit:
        print("GAME OVER")
        break
        
    time.sleep(random.uniform(0.5, 1.5))
``

### 11. Common Mistakes
*   **Wiring**: Button 0 must match LED 0 physically.
*   **Holding**: Player holding all buttons wins? Add check that buttons must be released first.

### 12. Try This Next
*   **Speed Up**: Reduce the 1000ms timeout by 50ms each round.
*   **Lives**: Allow 3 misses.

### 6. Blocks Used

### 7. Variables
*   ****duty**: 0-65535**

### 8. Step-by-Step Guide
**A. Initialization Phase**
1.  **Setup**:
  *   From **Motion & Motors**, set up PWM on GP16.
  *   **Snap** into setup block.

**B. Main Loop Phase**
1.  **Fade Buffer**:
  *   From **Loops**, drag `pico_forever`.
  *   **Snap** into loop.
2.  **Fade In**:
  *   From **Loops**, drag `count_with` block (count `duty` from 0 to 65000 by 1000).
  *   **Snap** into loop.
  *   From **Motion & Motors**, drag `pwm_duty` block (Pin 16, `duty`).

  *   **Snap** below duty block.
3.  **Fade Out**:
  *   From **Loops**, drag `count_with` block (count `duty` from 65000 to 0 by -1000).
  *   **Snap** below fade in loop.

### 9. Execution Flow
By rapidly changing the duty cycle (ratio of On vs Off time), the eye perceives dimming. Small steps make it smooth.

### 10. Generated Code
``python
import machine, time
pwm = machine.PWM(machine.Pin(16))
pwm.freq(1000)

while True:
    # Fade In
    for duty in range(0, 65535, 1000):
        pwm.duty_u16(duty)
        time.sleep(0.005)
    # Fade Out

  *   From **Variables**, create list `song` of tuples [(659, 0.1), ...].
  *   **Snap** into setup.

**B. Playback Loop**
1.  **Sequencer**:
  *   From **Loops**, drag `pico_forever`.
  *   From **Loops**, loop `note` in `song`.
  *   **Snap** into loop.
2.  **Decode Note**:
  *   From **Variables**, set `freq` to `note[0]`.
  *   From **Variables**, set `dur` to `note[1]`.
  *   **Snap** inside loop.
3.  **Play/Rest**:
  *   From **Logic**, if `freq` > 0:
      *   From **Motion & Motors**, set Freq `freq`.
      *   From **Motion & Motors**, set Duty 50%.
  *   Else:
      *   From **Motion & Motors**, set Duty 0%.
  *   **Snap** below decode.
4.  **Smart IO**:
  *   from **Smart IO**, wait `dur`.
  *   From **Motion & Motors**, set Duty 0%.
  *   from **Smart IO**, wait 0.05s (Articulation Gap).
  *   **Snap** below if/else.

### 9. Execution Flow
The first true 'Music Engine'. It decouples Note (Frequency) from Duration (Time), allowing complex rhythms (eighth notes, quarter notes, rests).

### 10. Generated Code
``python
import machine, time
buzzer = machine.PWM(machine.Pin(15))
# E5, E5, Rest, E5, Rest, C5, E5, Rest, G5
song = [
    (659, 0.15), (659, 0.15), (0, 0.15), (659, 0.15), (0, 0.15), (523, 0.15), (659, 0.15), (0, 0.15), (784, 0.4)
]

while True:
    for note in song:
        freq = note[0]; dur = note[1]
        if freq > 0:
            buzzer.freq(freq)
            buzzer.duty_u16(32768)
        else:
            buzzer.duty_u16(0)
        time.sleep(dur)
        buzzer.duty_u16(0) # Artifact gap
        time.sleep(0.02)
    time.sleep(2)
``

### 11. Common Mistakes
*   **Tuple Indexing**: `note[0]` vs `note[1]`. Python uses 0-based indexing.
*   **Synchrony**: The gap (0.02) adds to total time. Reduce `time.sleep(dur)` by 0.02 to keep tempo strict.

*   **Transpose**: Add variable `offset` to all frequencies.

``python

leds = [machine.PWM(machine.Pin(i)) for i in range(16, 19)]
for l in leds: l.freq(1000)

def set_hsl(h, s, l):
    # Simplest HSL to RGB algorithm for Hue cycling
    c = (1 - abs(2*l - 1)) * s
    x = c * (1 - abs((h/60) % 2 - 1))
    m = l - c/2
    
    if 0 <= h < 60: r,g,b = c,x,0
    elif 60 <= h < 120: r,g,b = x,c,0
    elif 120 <= h < 180: r,g,b = 0,c,x
    elif 180 <= h < 240: r,g,b = 0,x,c
    elif 240 <= h < 300: r,g,b = x,0,c
    elif 300 <= h < 360: r,g,b = c,0,x
    else: r,g,b = 0,0,0
    
    leds[0].duty_u16(int((r+m)*65535))
    leds[1].duty_u16(int((g+m)*65535))
    leds[2].duty_u16(int((b+m)*65535))

while True:
    for h in range(360):
        set_hsl(h, 1.0, 0.5)
        time.sleep(0.05)
``

### 11. Common Mistakes
*   **Float Math**: Python handles floats well on Pico, but they are slower than Ints. Not an issue for lights.
*   **Gamma**: Colors might look 'washed out' without gamma correction.

lock = machine.Pin(16, machine.Pin.OUT)
knocks = 0
start = 0

    if val > 10000:
        print("KNOCK")
        if knocks == 0: start = time.ticks_ms()
        knocks += 1
        time.sleep(0.2)

        if time.ticks_diff(time.ticks_ms(), start) > 2000:
            print("TIMEOUT")
            knocks = 0

        print("UNLOCK")
        lock.on(); time.sleep(3); lock.off()
        knocks = 0

    led.on(); time.sleep(unit); led.off(); time.sleep(unit)

    led.on(); time.sleep(unit*3); led.off(); time.sleep(unit)

    time.sleep(unit*2) # +1 from dot/dash = 3 units

    dot(); dot(); dot(); dot(); gap()
    # E

    # L

## 100. Project 0700: Mastering Morse Code

### 7. Variables

*   ****wpm_overall**: Int**

### 8. Step-by-Step Guide
**A. Initialization Phase**
1.  **Variables**:
  *   From **Variables**, set `wpm_char` to 20.
  *   From **Variables**, set `wpm_overall` to 5.
  *   **Snap** into setup block.
2.  **Calculations**:
  *   From **Math**, set `unit` to (1.2 / `wpm_char`).
  *   From **Math**, set `farnsworth_delay` to ( (1.2 / `wpm_overall`) - `unit` ).
  *   **Snap** below variables.

**B. Function Definition**
1.  **Signal Helper**:
  *   From **Functions**, create `play_char` with input `char`.
  *   From **Logic**, if `char` in `morse`:
      *   From **Loops**, loop `s` in `morse`[`char`]:
           *   From **Motion & Motors**, turn Buzzer On.
           *   from **Smart IO**, wait `unit` (if `.`) else `unit`*3.
           *   From **Motion & Motors**, turn Buzzer Off.
           *   from **Smart IO**, wait `unit`.
  *   from **Smart IO**, wait `farnsworth_delay`.
  *   **Snap** into setup.

**C. Main Loop Phase**
1.  **Transmission**:
  *   From **Loops**, drag `pico_forever`.
  *   Call `play_char` ("H").
  *   Call `play_char` ("I").
  *   **Snap** into loop.

### 9. Execution Flow
The standard way to learn Morse. Prevents 'counting dots' by making the symbols too fast to count, while giving thinking time between them.

### 10. Generated Code
``python
import machine, time
buz = machine.PWM(machine.Pin(16))
morse = {'H': '....', 'I': '..'}

wpm_char = 20
wpm_overall = 5

unit = 1.2 / wpm_char
# Standard word is 50 units.
# Delay calculation is complex using standard formula:
# Ta = (60*C - 37.2*W) / W  ... where C=Overall, W=CharSpeed. 
# Simplified: Just add extra gap.
extra_gap = (60/wpm_overall) - (60/wpm_char) # Rough approx for demo

def play(char):
    if char in morse:
        for s in morse[char]:
            buz.freq(600); buz.duty_u16(32768)
            time.sleep(unit if s=='.' else unit*3)
            buz.duty_u16(0); time.sleep(unit)
    time.sleep(extra_gap)

while True:
    play('H')
    play('I')
``

### 11. Common Mistakes
*   **Math Error**: Farnsworth math is tricky. The key is just 'Longer Spaces'.
*   **Drift**: Accumulating floating point errors.
