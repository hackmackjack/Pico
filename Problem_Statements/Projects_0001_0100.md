## Batch 1: LED Patterns 1 (3-5 (Elementary))

### Project 0001: Introduction to LED Patterns
**Category:** Basics & Digital I/O
**Difficulty:** 1 | **Bloom's:** Remember/Understand

**Problem Statement:**
Start your journey by controlling a single light. Create a system where the on-board LED turns ON for exactly 2 seconds, then turns OFF for 2 seconds, repeating forever. This introduces the concept of a "Loop" and "Time".

**Hardware Requirements:**
*   Pico
*   On-board LED (GP25 or Wireless LED)

**Expected Behavior:**
*   LED lights up bright.
*   LED goes dark.
*   Repeats consistently.

### Project 0002: Blinking LED Patterns
**Category:** Basics & Digital I/O
**Difficulty:** 1 | **Bloom's:** Remember/Understand

**Problem Statement:**
Modify your pattern to create a "Heartbeat". The LED should blink twice quickly (ON 0.2s, OFF 0.2s, ON 0.2s), then wait for a longer pause (OFF 1.0s) before restarting.

**Hardware Requirements:**
*   Pico
*   Red LED

**Expected Behavior:**
*   Double-flash effect.
*   One second pause.

### Project 0003: Manual LED Patterns Control
