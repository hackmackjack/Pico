
# 🏁 Batch 17: Ultrasonic Distance (HC-SR04)

## 1️⃣ Project 0161: Basic Distance Read

### 2️⃣ Learning Objective
Measure how far away an object is using sound waves.

### 3️⃣ Concepts Introduced
*   **Sonar (Echolocation)**: Sending a "Ping" and waiting for the echo.
*   **Speed of Sound**: Distance = (Time * Speed) / 2.

### 4️⃣ Hardware Required
*   **Pico**
*   **HC-SR04 Sensor** (4 Pins: VCC, Trig, Echo, GND)

### 5️⃣ Wiring / Interfaces
| Component | Pico Pin |
| :--- | :--- |
| **VCC** | VBUS (5V) |
| **Trig** | GP16 |
| **Echo** | GP17 |
| **GND** | GND |

### 6️⃣ Blocks Used
🔹 **Read Distance (HC-SR04)**
*   **Category:** Sensors
*   **Block:** `Read Distance Trig:[16] Echo:[17] unit:[cm]`

### 7️⃣ Variables & State
*   **dist**

### 8️⃣ Step-by-Step Guide
*   **1. Loop**
    *   From **Sensors**, drag `set [dist] to Read Distance Trig:[16] Echo:[17]`.
    *   From **Text**, drag `Print [dist]`.
    *   From **Timing**, drag `sleep [0.5] seconds`.

### 9️⃣ Execution Flow (Plain English)
The sensor shouts a sound we can't hear. It waits for the sound to bounce back. The Pico calculates the distance based on the flight time.

### 🔟 Generated Code (Reference Only)
```python
import machine, time
from hcsr04 import HCSR04
sensor = HCSR04(trigger_pin=16, echo_pin=17)
while True:
    print(sensor.distance_cm())
    time.sleep(0.5)
```

### 1️⃣1️⃣ Common Mistakes & Debug Tips
*   **Use 5V**: The HC-SR04 usually needs 5V (VBUS). If you use 3.3V, it might be weak or fail.
*   **Soft Objects**: Fabric or stuffed animals absorb sound and don't echo well. Use a hard book.

### 1️⃣2️⃣ Try This Next
*   **Unit**: Switch block to measure in "Inches".

## 1️⃣ Project 0162: Parking Sensor (Beep Speed)

### 2️⃣ Learning Objective
Beep faster as you get closer to the wall.

### 3️⃣ Concepts Introduced
*   **Frequency Mapping**: Distance -> Beep Delay.

### 4️⃣ Hardware Required
*   **Pico**
*   **HC-SR04**
*   **Buzzer**

### 5️⃣ Wiring / Interfaces
*(Sonar GP16/17, Buzzer GP15)*

### 6️⃣ Blocks Used
🔹 **Map Range**
🔹 **Play Tone**
🔹 **Wait**

### 7️⃣ Variables & State
*   **dist**

### 8️⃣ Step-by-Step Guide
*   **1. Loop**
    *   `dist` = Read Distance.
    *   **Logic**:
        *   From **Logic**, drag `if [dist] < [50]`. (Car is close).
        *   **Then**:
            *   Play Tone (Buzzer ON).
            *   Wait 0.05s.
            *   Stop Tone (Buzzer OFF).
            *   Wait `dist` / 100 seconds. (10cm = 0.1s wait. 50cm = 0.5s wait).

### 9️⃣ Execution Flow (Plain English)
Beep... Beep... Beep..Beep.Beep.BEEEEEP.

### 🔟 Generated Code (Reference Only)
```python
val = sensor.distance_cm()
if val < 50:
    buzz.on(); time.sleep(0.05); buzz.off()
    time.sleep(val/100)
```

### 1️⃣1️⃣ Common Mistakes & Debug Tips
*   **Negative Math**: Ideally clamp distance so we don't accidentally `sleep(-1)` which crashes code.

### 1️⃣2️⃣ Try This Next
*   **Solid Tone**: If dist < 5cm, keep buzzer ON permanently (CRASH!).

### 2️⃣ Learning Objective
Detect movement in a stationary room.

### 3️⃣ Concepts Introduced
*   **Baseline Calibration**: "The wall is 200cm away". If it becomes 100cm, that's not the wall, that's a person."

### 4️⃣ Hardware Required
*   **Pico**
*   **HC-SR04**
*   **Buzzer**

### 5️⃣ Wiring / Interfaces
*(Standard)*

### 6️⃣ Blocks Used
🔹 **If**
🔹 **Variables**

### 7️⃣ Variables & State
*   **baseline**

### 8️⃣ Step-by-Step Guide
*   **1. Setup**
    *   `baseline` = Read Distance.
    *   Print "Calibrated: " + `baseline`.
*   **2. Loop**
    *   `current` = Read Distance.
    *   **Logic**:
        *   From **Logic**, drag `if [current] < [baseline - 20]`.
        *   Then: Alarm (Person is in front of wall).
    *   Wait 0.2s.

### 9️⃣ Execution Flow (Plain English)
It memorizes the distance to the far wall. If anything blocks that view (making the distance shorter), it triggers.

### 🔟 Generated Code (Reference Only)
```python

        Alarm()
```

## 1️⃣ Project 0170: Mastering Sonar (Echo Filtering)

### 2️⃣ Learning Objective
Fix "0" readings and jittery spikes.

### 3️⃣ Concepts Introduced
*   **Median Filter**: Taking 5 readings and throwing away the outliers.

### 4️⃣ Hardware Required
*   **Pico**
*   **HC-SR04**

### 5️⃣ Wiring / Interfaces
*(Standard)*

### 6️⃣ Blocks Used
🔹 **List**
🔹 **Sort**

### 7️⃣ Variables & State
*   **readings_list**

### 8️⃣ Step-by-Step Guide
*   **1. Loop**
    *   Set `readings_list` = Empty List.
    *   **Collect**:
        *   Repeat 5 times:
            *   Add `Read Distance` to `readings_list`.
            *   Wait 0.05s.
    *   **Filter**:
        *   Sort `readings_list` (Numerical).
        *   `median` = Get Item [3] from `readings_list` (The middle one).
    *   Print `median`.

### 9️⃣ Execution Flow (Plain English)
If we read [20, 20, 2000, 19, 21]. The "2000" is an error. Sorting gives [19, 20, 20, 21, 2000]. The middle is 20. Perfect.

### 🔟 Generated Code (Reference Only)
```python
vals = []
for i in range(5):
    vals.append(sensor.distance())
vals.sort()
print(vals[2])
```

### 1️⃣1️⃣ Common Mistakes & Debug Tips
*   **Cost**: Sorting takes CPU time. Don't do it with 100 items.

### 1️⃣2️⃣ Try This Next
*   **Timeout**: Modify the library to stop listening after 30ms (5 meters) to prevent long lags.
