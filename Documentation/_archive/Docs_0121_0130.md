## 1️⃣ Project 0121: Read Temperature (DHT11)

### 2️⃣ Learning Objective
Learn to use a complex digital sensor. Unlike the Potentiometer (Analog), the DHT11 sends digital messages containing both Temperature and Humidity.

### 3️⃣ Concepts Introduced
*   **Digital Communication**: Handshaking and timing to read data.
*   **Poll Frequency**: You cannot read DHT11 faster than once every 2 seconds.

### 4️⃣ Hardware Required
*   **Pico**
*   **DHT11 Sensor** (3 or 4 pins)
*   **10k Resistor** (If module doesn't have one builtin)

### 5️⃣ Wiring / Interfaces
| Component | Pico Pin |
| :--- | :--- |
| **VCC** | 3.3V (or 5V depending on module) |
| **Signal** | GP15 |
| **GND** | GND |

### 6️⃣ Blocks Used
🔹 **Read DHT Temperature**
*   **Category:** Sensors
*   **Block:** `Read DHT11 on pin [15]`
*   **Block:** `Get Temperature`

### 7️⃣ Variables & State
*   **temp_val**

### 8️⃣ Step-by-Step Guide
*   **1. Loop**
    *   From **Sensors**, drag `Read DHT11 on pin [15]`.
    *   **Get Value**:
        *   From **Variables**, create `temp_val`.
        *   Set `temp_val` to `Get Temperature`.
    *   **Output**:
        *   From **Text**, drag `Print [temp_val]`.
    *   **Wait**:
        *   From **Timing**, drag `sleep [2] seconds`.

### 9️⃣ Execution Flow (Plain English)
The Pico wakes up the sensor. The sensor measures the air and sends back the degrees Celsius. We print it. We MUST wait 2 seconds because the sensor is slow.

### 🔟 Generated Code (Reference Only)
```python
import machine
import dht
import time
sensor = dht.DHT11(machine.Pin(15))
while True:
    try:
        sensor.measure()
        temp = sensor.temperature()
        print(temp)
    except OSError as e:
        print("Failed to read")
    time.sleep(2)
```

### 1️⃣1️⃣ Common Mistakes & Debug Tips
*   **Reading Too Fast**: If you sleep 0.1s, you will get "OSError" or "Nan". Keep it > 2s.
*   **Wiring**: Pay attention to VCC vs Signal.

### 1️⃣2️⃣ Try This Next
*   **Fahrenheit**: Math: `(C * 1.8) + 32`.

### 3️⃣ Concepts Introduced

### 6️⃣ Blocks Used

## 1️⃣ Project 0127: Min/Max Logger

### 2️⃣ Learning Objective
Remember the highest and lowest temperatures seen since powered on.

### 3️⃣ Concepts Introduced
*   **State Retention**: Keeping `max_temp` stored in variable.
*   **Comparison**: If `current` > `max`, then `max` = `current`.

### 4️⃣ Hardware Required
*   **Pico**
*   **DHT11**

### 5️⃣ Wiring / Interfaces
*(Standard)*

### 6️⃣ Blocks Used
🔹 **If**
🔹 **Math Constants**

### 7️⃣ Variables & State
*   **min_t** (Set to 100 initially)
*   **max_t** (Set to -100 initially)
*   **curr_t**

### 8️⃣ Step-by-Step Guide
*   **1. Setup Variables**
    *   Set `min_t` to 100.
    *   Set `max_t` to -100.
*   **2. Loop**
    *   Measure DHT11.
    *   `curr_t` = Temp.
    *   **Check Max**:
        *   From **Logic**, drag `if [curr_t] > [max_t]`.
        *   Then: Set `max_t` to `curr_t`.
    *   **Check Min**:
        *   From **Logic**, drag `if [curr_t] < [min_t]`.
        *   Then: Set `min_t` to `curr_t`.
    *   Print "Max: " + `max_t` + " Min: " + `min_t`.
    *   Wait 2s.

### 9️⃣ Execution Flow (Plain English)
We start with impossible defaults (Max=-100). The first reading (25C) is > -100, so Max becomes 25. If it gets hotter (26C), Max updates. If it cools (24C), Max stays 26C.

### 🔟 Generated Code (Reference Only)
```python
min_t = 100
max_t = -100
while True:
    # ... read t ...
    if t > max_t: max_t = t
    if t < min_t: min_t = t
    # ...
```

### 1️⃣1️⃣ Common Mistakes & Debug Tips
*   **Reset**: The memory is lost if you unplug the Pico.

### 1️⃣2️⃣ Try This Next

## 1️⃣ Project 0130: Mastering Sensors (Non-Blocking)

### 2️⃣ Learning Objective
Read the slow Sensor without freezing the button inputs.

### 3️⃣ Concepts Introduced
*   **Timing Intervals**: Read sensor every 2s, but check button every 0.01s.

### 4️⃣ Hardware Required
*   **Pico**
*   **DHT11**
*   **Button** (GP16)
*   **LED** (GP14)

### 5️⃣ Wiring / Interfaces
*(Standard + Button)*

### 6️⃣ Blocks Used
🔹 **Time (Ticks)**
🔹 **If (Timer)**

### 7️⃣ Variables & State
*   **last_read_time**

### 8️⃣ Step-by-Step Guide
*   **1. Setup**
    *   `last_read_time` = 0.
*   **2. Loop**
    *   **Fast Task (Button)**:
        *   From **Logic**, drag `if Button is Pressed`.
        *   Then: Toggle LED.
    *   **Slow Task (Sensor)**:
        *   From **Logic**, drag `if (Time Now - last_read_time) > 2000`.
        *   Then:
            *   Measure DHT11.
            *   Print values.
            *   Set `last_read_time` to Time Now.

### 9️⃣ Execution Flow (Plain English)
The loop spins very fast. 99% of the time, it just checks the button (instant response). But if 2 seconds have passed, it quickly reads the sensor then goes back to button checking.

### 🔟 Generated Code (Reference Only)
```python
last = 0
while True:
    if btn.value():
        led.toggle()
        time.sleep(0.2) # Debounce
    
    now = time.ticks_ms()
    if time.ticks_diff(now, last) > 2000:
        sensor.measure()
        print(sensor.temperature())
        last = now
```

### 1️⃣1️⃣ Common Mistakes & Debug Tips
*   **DHT Speed**: Even with this code, the `sensor.measure()` line takes about 0.2s to execute, so there is a tiny hiccup.
