## 1️⃣ Project 0141: Basic Sweep

### 2️⃣ Learning Objective
Move a motor arm back and forth automatically. Unlike separate DC motors (which spin freely), a Servo goes to a specific angle (0° to 180°).

### 3️⃣ Concepts Introduced
*   **PWM (Pulse Width Modulation)**: Using precise timing pulses to tell the servo where to point.
*   **Angle**: 0 degrees (Left), 90 degrees (Center), 180 degrees (Right).

### 4️⃣ Hardware Required
*   **Pico**
*   **Micro Servo** (SG90) (3 Wires: Brown, Red, Orange)

### 5️⃣ Wiring / Interfaces
| Component | Pico Pin | Notes |
| :--- | :--- | :--- |
| **Brown** | GND | Ground |
| **Red** | VBUS (5V) | Servos need power! |
| **Orange** | GP16 | Signal (PWM) |

### 6️⃣ Blocks Used
🔹 **Servo Write**
*   **Category:** Motors
*   **Block:** `Rotate Servo pin [16] to [angle]`

### 7️⃣ Variables & State
*   None.

### 8️⃣ Step-by-Step Guide
*   **1. Loop**
    *   From **Motors**, drag `Rotate Servo pin [16] to [0]`.
    *   From **Timing**, drag `sleep [1] seconds`.
    *   From **Motors**, drag `Rotate Servo pin [16] to [180]`.
    *   From **Timing**, drag `sleep [1] seconds`.

### 9️⃣ Execution Flow (Plain English)
The arm moves all the way left. Waits. Moves all the way right. Waits. Repeat.

### 🔟 Generated Code (Reference Only)
```python
import machine
import time
servo = machine.PWM(machine.Pin(16))
servo.freq(50)
while True:
    # 0 degrees ~ 1000 duty, 180 ~ 9000 duty (Depends on servo)
    servo.duty_u16(1000); time.sleep(1)
    servo.duty_u16(9000); time.sleep(1)
```

### 1️⃣1️⃣ Common Mistakes & Debug Tips
*   **Buzzing**: If the servo pushes against the physical stopper, it will buzz and get hot. Change 180 to 170.
*   **Power**: If the Pico reboots when the servo moves, the servo is stealing too much power. Use a separate battery pack.

### 1️⃣2️⃣ Try This Next
*   **Speed**: Change sleep to 0.1s for a frantic wiper.

## 1️⃣ Project 0143: Slow Motion Movement

### 2️⃣ Learning Objective
Make the servo move smoothly instead of jumping instantly.

### 3️⃣ Concepts Introduced
*   **for Loops**: Iterating through angles one by one.
*   **Delay**: Small pauses between steps control speed.

### 4️⃣ Hardware Required
*   **Pico**
*   **Servo**

### 5️⃣ Wiring / Interfaces
*(Standard)*

### 6️⃣ Blocks Used
🔹 **Count with (i from 0 to 180)** (Category: Loops)

### 7️⃣ Variables & State
*   **angle**

### 8️⃣ Step-by-Step Guide
*   **1. Loop**
    *   **Sweep Up**:
        *   From **Loops**, drag `count with [angle] from [0] to [180] by [1]`.
        *   Inside Loop:
            *   `Rotate Servo pin [16] to [angle]`.
            *   Wait 0.01s.
    *   **Sweep Down**:
        *   From **Loops**, drag `count with [angle] from [180] to [0] by [-1]`.
        *   Inside Loop:
            *   `Rotate Servo pin [16] to [angle]`.
            *   Wait 0.01s.

### 9️⃣ Execution Flow (Plain English)
It goes 0, 1, 2, 3... 180. The servo updates 100 times a second, creating a silky smooth motion.

### 🔟 Generated Code (Reference Only)
```python
for angle in range(0, 181, 1):
    # map angle to duty
    servo.duty_u16(d)
    time.sleep(0.01)
```

### 1️⃣1️⃣ Common Mistakes & Debug Tips
*   **Too Fast**: If `sleep` is 0, it will just jump.
*   **Too Slow**: If `sleep` is 0.1, it will act like a ticking clock (step-step-step).

### 1️⃣2️⃣ Try This Next
*   **Variable Speed**: Make the sweep up fast (0.005) and sweep down slow (0.05).

## 1️⃣ Project 0146: Servo Lock (Door Mechanism)

### 2️⃣ Learning Objective
Simulate a smart deadbolt.

### 3️⃣ Concepts Introduced
*   **Security Logic**: Only unlock if the "Key" (Button) is correct.
*   **Feedback**: LED indicates status (Red=Locked, Green=Unlocked).

### 4️⃣ Hardware Required
*   **Pico**
*   **Servo**
*   **Red LED** (GP14)
*   **Green LED** (GP15)
*   **Button** (GP13)

### 5️⃣ Wiring / Interfaces
*(Servo GP16, LEDs GP14/15, Btn GP13)*

### 6️⃣ Blocks Used
🔹 **If / Else**
🔹 **Set Variable** (is_locked)

### 7️⃣ Variables & State
*   **is_locked** (True/False)

### 8️⃣ Step-by-Step Guide
*   **1. Setup**
    *   Set `is_locked` = True.
*   **2. Loop**
    *   IF Button Pressed:
        *   Set `is_locked` = NOT `is_locked`. (Flip state).
        *   Wait 0.5s (Debounce).
    *   **Actuate**:
        *   IF `is_locked`:
            *   `Rotate Servo [16] to [0]`.
            *   Turn Red LED ON.
        *   ELSE:
            *   `Rotate Servo [16] to [90]`.
            *   Turn Green LED ON.

### 9️⃣ Execution Flow (Plain English)
Tap the button to toggle the lock. The servo rotates 90 degrees to slide the bolt.

### 🔟 Generated Code (Reference Only)
```python
# ... 
if locked:
    servo.duty_u16(1000)
    red.value(1)
```

### 1️⃣1️⃣ Common Mistakes & Debug Tips
*   **Mechanical**: The hard part is actually attaching this to a cardboard door. Use tape and paperclips!

### 1️⃣2️⃣ Try This Next
*   **Password**: Require 3 button presses to unlock.

## 1️⃣ Project 0147: Metronome

### 2️⃣ Learning Objective
Keep precise time with a visual swinging arm.

### 3️⃣ Concepts Introduced
*   **BPM (Beats Per Minute)**: Converting Music Tempo to Motor Speed.

### 4️⃣ Hardware Required
*   **Pico**
*   **Servo**
*   **Pot** (Speed Control)

### 5️⃣ Wiring / Interfaces
*(Servo GP16, Pot GP26)*

### 6️⃣ Blocks Used
🔹 **Map Range**
🔹 **Wait**

### 7️⃣ Variables & State
*   **bpm**, **delay_time**

### 8️⃣ Step-by-Step Guide
*   **1. Loop**
    *   `bpm` = Read Pot (Map to 40-200).
    *   `delay_time` = 60 / `bpm`.
    *   **Tick**:
        *   `Rotate Servo [16] to [45]`.
        *   Wait `delay_time` seconds.
    *   **Tock**:
        *   `Rotate Servo [16] to [135]`.
        *   Wait `delay_time` seconds.

### 9️⃣ Execution Flow (Plain English)
Tick... Tock... Tick... Tock. Turning the knob changes the rhythm (Adagio vs Allegro).

### 🔟 Generated Code (Reference Only)
```python
bpm = 40 + (adc.read_u16()/65535)*160
wait = 60/bpm
servo.duty(left)
time.sleep(wait)
servo.duty(right)
time.sleep(wait)
```

### 1️⃣1️⃣ Common Mistakes & Debug Tips
*   **Physics**: A servo is not a pendulum. It moves rigidly. Real metronomes use gravity.

### 1️⃣2️⃣ Try This Next

## 1️⃣ Project 0150: Mastering Servos (Power & Jitter)

### 2️⃣ Learning Objective
Fixing the shaky servo problem using software "Detach".

### 3️⃣ Concepts Introduced
*   **Duty Cycle 0**: Turning off the signal so the motor relaxes.

### 4️⃣ Hardware Required
*   **Pico**
*   **Servo**

### 5️⃣ Wiring / Interfaces
*(GP16)*

### 6️⃣ Blocks Used
🔹 **Analog Write (PWM)** (Advanced)

### 7️⃣ Variables & State
*   None.

### 8️⃣ Step-by-Step Guide
*   **1. Loop**
    *   **Move**:
        *   `Rotate Servo [16] to [90]`.
        *   Wait 1s (Time to get there).
    *   **Detach (Relax)**:
        *   From **Smart IO**, drag `Analog Write Pin [16] value [0]`. (Stop sending PWM).
    *   Wait 5s.

### 9️⃣ Execution Flow (Plain English)
The servo moves to 90. Then we cut the signal. The servo goes "limp" (stops humming). It stays in place due to friction. This saves power and stops the annoying buzzing noise.

### 🔟 Generated Code (Reference Only)
```python
servo.duty_u16(4500)
time.sleep(1)
servo.duty_u16(0) # Off
time.sleep(5)
```

### 1️⃣1️⃣ Common Mistakes & Debug Tips
*   **Holding Torque**: If the arm is holding a heavy weight, "Detaching" will cause it to fall! Only use this for lightweight things (like a lock or flag).

### 1️⃣2️⃣ Try This Next
*   **Random**: Move to random spot, detach, wait, repeat.
