## 1️⃣ Project 0131: Basic Lux Meter

### 2️⃣ Learning Objective
Measure how bright a room is. An LDR (Light Dependent Resistor) changes its resistance based on light.

### 3️⃣ Concepts Introduced
*   **Voltage Divider**: LDRs change resistance, but the Pico reads voltage. We use a fixed resistor to convert Resistance -> Voltage.
*   **Inverse Relationship**: More Light = Less Resistance = Higher Voltage (usually).

### 4️⃣ Hardware Required
*   **Pico**
*   **LDR (Photoresistor)**
*   **10kΩ Resistor**

### 5️⃣ Wiring / Interfaces
| Component | Pico Pin |
| :--- | :--- |
| **LDR Leg 1** | 3.3V |
| **LDR Leg 2** | GP26 (And to Resistor) |
| **Resistor** | GP26 to GND |

### 6️⃣ Blocks Used
🔹 **Read Analog** (GP26)
🔹 **Print**

### 7️⃣ Variables & State
*   **light_level**

### 8️⃣ Step-by-Step Guide
*   **1. Loop**
    *   From **Pin Access**, drag `read analog pin [26]`.
    *   From **Variables**, set `light_level` to the read value.
    *   From **Text**, drag `print [light_level]`.
    *   From **Timing**, drag `sleep [0.5] seconds`.

### 9️⃣ Execution Flow (Plain English)
In the dark, the resistance is high, so the voltage at GP26 is low (near 0). In bright light, resistance drops, and voltage rises (near 65535). Use the Serial Plotter to see the wave when you wave your hand.

### 🔟 Generated Code (Reference Only)
```python
import machine
import time
ldr = machine.ADC(26)
while True:
    print(ldr.read_u16())
    time.sleep(0.5)
```

### 1️⃣1️⃣ Common Mistakes & Debug Tips
*   **Resistor**: You MUST have the 10k resistor. Without it, the value will be stuck at 65535 or 0. This is a "Pull-Down" resistor configuration.

### 1️⃣2️⃣ Try This Next
*   **Flashlight**: Shine a light and see max value. Cover with tape and see min value.

    *   `raw` = Read LDR.
    *   `freq` = Map `raw` (0-65535) to (100-2000).
    *   From **Audio**, drag `Play Tone on [GP15] frequency [freq]`.

### 9️⃣ Execution Flow (Plain English)

## 1️⃣ Project 0135: Solar Tracker (Dual LDR)

### 2️⃣ Learning Objective
Compare two sensors to find the brightest spot. This logic is used in solar panels to follow the sun.

### 3️⃣ Concepts Introduced
*   **Differential Logic**: `Left - Right`.
*   **Decision**: If Left > Right, move Left.

### 4️⃣ Hardware Required
*   **Pico**
*   **2x LDRs**
*   **LCD** (or Print to Serial)

### 5️⃣ Wiring / Interfaces
| Component | Pico Pin |
| :--- | :--- |
| **LDR Left** | GP26 |
| **LDR Right** | GP27 |

### 6️⃣ Blocks Used
🔹 **Compare**
🔹 **LCD Print**

### 7️⃣ Variables & State
*   **left**, **right**

### 8️⃣ Step-by-Step Guide
*   **1. Loop**
    *   Set `left` = Read GP26.
    *   Set `right` = Read GP27.
    *   **Logic**:
        *   From **Logic**, drag `if [left] > [right + 1000]`.
        *   Then: Print "Turn Left <<".
        *   Else If `[right] > [left + 1000]`.
        *   Then: Print "Turn Right >>".
        *   Else: Print "Centered".
    *   Wait 0.2s.

### 9️⃣ Execution Flow (Plain English)
If the left sensor is brighter, the sun is on the left. We add `1000` as a "buffer" (deadzone) so it doesn't jitter when they are equal.

### 🔟 Generated Code (Reference Only)
```python
# ...
if left > right + 1000:
    print("Left")
elif right > left + 1000:
    print("Right")
```

### 1️⃣1️⃣ Common Mistakes & Debug Tips
*   **Shadow**: Put a piece of cardboard *between* the two sensors so a shadow falls on one if the light is angled.

### 1️⃣2️⃣ Try This Next

## 1️⃣ Project 0136: Motion Gesture (Swipe Hand)

### 2️⃣ Learning Objective
Detect a direction of movement. Left-to-Right vs Right-to-Left.

### 3️⃣ Concepts Introduced
*   **Sequence Detection**: Event A happened, THEN Event B happened.

### 4️⃣ Hardware Required
*   **Pico**
*   **2x LDRs** (spaced 5cm apart)

### 5️⃣ Wiring / Interfaces
*(LDR1 GP26, LDR2 GP27)*

### 6️⃣ Blocks Used
🔹 **Variables** (Flags)
🔹 **Time**

### 7️⃣ Variables & State
*   **triggered_1**, **time_1**

### 8️⃣ Step-by-Step Guide
*   **1. Loop**
    *   IF `LDR1` < Dark AND `triggered_1` is False:
        *   Set `triggered_1` = True.
        *   Set `time_1` = Time Now.
    *   IF `LDR2` < Dark AND `triggered_1` is True:
        *   IF (Time Now - `time_1`) < 500ms:
            *   Print "Swipe Right! ->".
            *   Set `triggered_1` = False. (Reset).

### 9️⃣ Execution Flow (Plain English)
If Sensor 1 goes dark, we start a timer. If Sensor 2 goes dark shortly after, it means an object moved from 1 to 2.

### 🔟 Generated Code (Reference Only)
```python
# Complex logic usually simplified in blocks
if ldr1 < 10000 and not trig1:
    trig1 = True
    start = time.ticks_ms()
if ldr2 < 10000 and trig1:
    if time.ticks_diff(time.ticks_ms(), start) < 500:
        print("Swipe >>>")
    trig1 = False
```

### 1️⃣1️⃣ Common Mistakes & Debug Tips
*   **Timeout**: We need to reset `triggered_1` to False if too much time passes, otherwise it remembers a shadow from an hour ago.

### 1️⃣2️⃣ Try This Next
*   **Pagination**: Use swipe to change pages on the LCD Menu (Project 107).

## 1️⃣ Project 0137: Optical Tachometer (Spin Speed)

### 2️⃣ Learning Objective
Count how fast something is spinning.

### 3️⃣ Concepts Introduced
*   **Edge Detection**: Counting pulses.
*   **RPM**: Revolutions Per Minute.

### 4️⃣ Hardware Required
*   **Pico**
*   **LDR** + **Laser/Light**
*   **Fan** (or something spinning)

### 5️⃣ Wiring / Interfaces
*(LDR GP26)*

### 6️⃣ Blocks Used
🔹 **Count**
🔹 **Timer**

### 7️⃣ Variables & State
*   **hits**

### 8️⃣ Step-by-Step Guide
*   **1. Loop**
    *   Wait for LDR < 10000 (Beam Broken by fan blade).
    *   Change `hits` by 1.
    *   Wait for LDR > 10000 (Beam Clear).
    *   IF 1 Second Passed:
        *   Print `hits` * 60 (RPM).
        *   Set `hits` = 0.

### 9️⃣ Execution Flow (Plain English)
Every time a blade passes, it blocks the light. We count the blocks.

### 🔟 Generated Code (Reference Only)
```python
while True:
    while ldr.read_u16() > 20000: pass # Wait for break
    hits += 1
    while ldr.read_u16() < 20000: pass # Wait for clear
```

### 1️⃣1️⃣ Common Mistakes & Debug Tips
*   **Speed**: LDRs are slow chemical sensors. They can't see very fast fans (Cadmium Sulfide has lag). Photodiodes are better for high speed.

### 1️⃣2️⃣ Try This Next
*   **Fan Control**: Adjust fan speed to maintain target RPM.

## 1️⃣ Project 0139: Morse Code Receiver (Light)

### 2️⃣ Learning Objective
Decode signals sent by light flashes (Li-Fi concept).

### 3️⃣ Concepts Introduced
*   **Time Measurement**: Differentiating Short pulse (Dot) vs Long pulse (Dash).

### 4️⃣ Hardware Required
*   **Pico**
*   **LDR**
*   **Flashlight** (Handheld)

### 5️⃣ Wiring / Interfaces
*(LDR GP26)*

### 6️⃣ Blocks Used
🔹 **Timer**

### 7️⃣ Variables & State
*   **pulse_len**

### 8️⃣ Step-by-Step Guide
*   **1. Loop**
    *   Wait for Light (Signal Start).
    *   Start Timer.
    *   Wait for Dark (Signal End).
    *   `pulse_len` = Stop Timer.
    *   **Logic**:
        *   From **Logic**, drag `if [pulse_len] < [400]`.
        *   Then: Print ".".
        *   Else: Print "-".

### 9️⃣ Execution Flow (Plain English)
You flash the light at the sensor. It measures how long the flash lasted. Short = Dot. Long = Dash.

### 🔟 Generated Code (Reference Only)
```python
while True:
    while ldr.read_u16() < 40000: pass # Wait for light
    start = time.ticks_ms()
    while ldr.read_u16() > 40000: pass # Wait for dark
    duration = time.ticks_diff(time.ticks_ms(), start)
    if duration < 400: print(".", end="")
    else: print("-", end="")
```

### 1️⃣1️⃣ Common Mistakes & Debug Tips
*   **Ambient Light**: This works best in a dim room. If the room is too bright, the LDR is always "High".

### 1️⃣2️⃣ Try This Next
*   **Decoder**: Combine with Project 100 to print real letters ("S", "O", "S").

## 1️⃣ Project 0140: Mastering Light (Calibration)

### 2️⃣ Learning Objective
Make your code work in ANY room, regardless of lighting.

### 3️⃣ Concepts Introduced
*   **Relative Measurement**: Defining "Dark" as "50% of the Start Value", not a fixed number like 10000.

### 4️⃣ Hardware Required
*   **Pico**
*   **LDR**

### 5️⃣ Wiring / Interfaces
*(LDR GP26)*

### 6️⃣ Blocks Used
🔹 **Variables**
🔹 **Math (%)**

### 7️⃣ Variables & State
*   **baseline**, **trigger_level**

### 8️⃣ Step-by-Step Guide
*   **1. Setup**
    *   Wait 1s (Stabilize).
    *   Set `baseline` = Read LDR.
    *   Set `trigger_level` = `baseline` - 10000.
    *   Print "Calibrated. Baseline:" + `baseline`.
*   **2. Loop**
    *   `current` = Read LDR.
    *   **Logic**:
        *   From **Logic**, drag `if [current] < [trigger_level]`.
        *   Then: Print "Shadow Detected".

### 9️⃣ Execution Flow (Plain English)
When you turn it on, it takes a "sample" of the room. It decides that "Shadow" means "Significantly darker than NOW". This makes the project portable.

### 🔟 Generated Code (Reference Only)
```python
time.sleep(1)
baseline = ldr.read_u16()
threshold = baseline - 10000
while True:
    if ldr.read_u16() < threshold:
        print("Shadow")
```

### 1️⃣1️⃣ Common Mistakes & Debug Tips
*   **Re-Calibrate**: You need to reset the board if the sun goes down or you turn on a room light.

### 1️⃣2️⃣ Try This Next
*   **Auto-Re-Cal**: If the sensor stays stable for 10s, update the baseline automatically.
