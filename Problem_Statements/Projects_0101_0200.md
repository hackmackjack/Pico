## Batch 11: Digital Art 1 (3-5 (Elementary))

### Project 0101: Introduction to Digital Art
**Category:** Displays & User Feedback
**Difficulty:** 1 | **Bloom's:** Remember/Understand

**Problem Statement:**
"Pixel Painter". Control a single RGB LED. Write a program to make it turn Red, then Green, then Blue, holding each color for 1 second. These are the primary colors of light.

**Hardware Requirements:**
*   Pico
*   RGB LED (or NeoPixel)

**Expected Behavior:**
*   Cycle R -> G -> B.
