
# 🏁 Batch 18: Neopixels (WS2812B)

## 1️⃣ Project 0171: Single Pixel Color

### 2️⃣ Learning Objective
Control an intelligent RGB LED that uses only 1 pin. Unlike regular RGB LEDs (3 pins), Neopixels have a built-in chip that handles color mixing.

### 3️⃣ Concepts Introduced
*   **Addressable LEDs**: Each pixel has an address (Pixel 0, Pixel 1...).
*   **RGB Values**: Red (0-255), Green (0-255), Blue (0-255).

### 4️⃣ Hardware Required
*   **Pico**
*   **WS2812B LED Strip** (or single pixel)

### 5️⃣ Wiring / Interfaces
| Component | Pico Pin |
| :--- | :--- |
| **VCC** | VBUS (5V) |
| **DIN** | GP15 |
| **GND** | GND |

### 6️⃣ Blocks Used
🔹 **Init Neopixel** (Category: Lights)
🔹 **Set Pixel Color**

### 7️⃣ Variables & State
*   None.

### 8️⃣ Step-by-Step Guide
*   **1. Setup**
    *   From **Lights**, drag `Setup Neopixel Pin:[15] Count:[8]`.
    *   **Snap** it into the setup area (before loop).
    *   Change Count to `1` (if you have only 1 pixel).
*   **2. Loop**
    *   From **Lights**, drag `Set Pixel [0] to R:[255] G:[0] B:[0]`.
    *   **Snap** it inside the forever loop.
    *   From **Lights**, drag `Show Neopixel`.
    *   **Snap** it below the Set Pixel block.
    *   From **Timing**, drag `sleep [1] seconds`.
    *   **Snap** it below Show.

### 9️⃣ Execution Flow (Plain English)
We tell Pixel 0 "Be Red". Then we call "Show" to actually make it happen. The LED turns red and stays red.

### 🔟 Generated Code (Reference Only)
```python
import machine, neopixel, time
np = neopixel.NeoPixel(machine.Pin(15), 1)
while True:
    np[0] = (255, 0, 0)
    np.write()
    time.sleep(1)
```

### 1️⃣1️⃣ Common Mistakes & Debug Tips
*   **Forgot Show**: If you set the color but don't call "Show", nothing happens.
*   **Power**: 1 pixel is fine on 3.3V. But 8+ pixels need 5V and external power.

### 1️⃣2️⃣ Try This Next
*   **Rainbow**: Set R:255, G:128, B:0 (Orange).

*   **8-pixel Neopixel Strip**

### 6️⃣ Blocks Used

### 7️⃣ Variables & State

### 8️⃣ Step-by-Step Guide
*   **1. Setup**
    *   From **Lights**, drag `Setup Neopixel Pin:[15] Count:[8]`.
    *   **Snap** into setup.
*   **2. Loop**
    *   From **Loops**, drag `count with [i] from [0] to [7] by [1]`.
    *   **Snap** it inside forever loop.
    *   From **Lights**, drag `Set Pixel [i] to R:[255] G:[0] B:[0]`.
    *   **Snap** it inside the count loop.
    *   Change the `[0]` to `[i]` (use the variable).
    *   From **Math**, drag the `*` block.
    *   Calculate `i * 30` for Red channel (creates gradient).

## 1️⃣ Project 0173: Chase Effect

### 2️⃣ Learning Objective
Create a moving light animation.

### 3️⃣ Concepts Introduced

### 4️⃣ Hardware Required
*   **Pico**
*   **Neopixel Strip**

### 5️⃣ Wiring / Interfaces
*(Standard)*

### 6️⃣ Blocks Used
🔹 **Fill Neopixel** (All Off)
🔹 **Set Pixel**

### 7️⃣ Variables & State
*   **pos**

### 8️⃣ Step-by-Step Guide
*   **1. Setup**
    *   Setup Neopixel (8 pixels).
*   **2. Loop**
    *   From **Loops**, drag `count with [pos] from [0] to [7] by [1]`.
    *   **Inside the count loop**:
        *   From **Lights**, drag `Fill All Pixels R:[0] G:[0] B:[0]`.
        *   **Snap** it first (clear all).
        *   From **Lights**, drag `Set Pixel [pos] to R:[0] G:[255] B:[0]`.
        *   **Snap** below Fill.
        *   From **Lights**, drag `Show Neopixel`.
        *   From **Timing**, drag `sleep [0.1] seconds`.

### 9️⃣ Execution Flow (Plain English)

    np.write()

*   **Tail**: If you want a "comet tail", don't clear. Just fade old pixels by 50% each frame.
