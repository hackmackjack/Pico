
# 🏁 Batch 16: Keypads (4x4 Matrix)

## 1️⃣ Project 0151: Read Key Press

### 2️⃣ Learning Objective
Read input from a 16-button keypad. Unlike 16 individual buttons (which would need 16 pins!), a matrix keypad uses a grid system to do it with only 8 pins.

### 3️⃣ Concepts Introduced
*   **Matrix Scanning**: Rows and Columns.
*   **Libraries**: We will use a `Keypad` block that handles the fast scanning for us.

### 4️⃣ Hardware Required
*   **Pico**
*   **4x4 Membrane Keypad**

### 5️⃣ Wiring / Interfaces
| Component | Pico Pin |
| :--- | :--- |
| **Row 1-4** | GP2, GP3, GP4, GP5 |
| **Col 1-4** | GP6, GP7, GP8, GP9 |

### 6️⃣ Blocks Used
🔹 **Init Keypad** (Category: Input)
🔹 **Get Key**

### 7️⃣ Variables & State
*   **key** (Strings: "1", "A", "*", etc.)

### 8️⃣ Step-by-Step Guide
*   **1. Setup**
    *   From **Input**, drag `Setup Keypad (Rows:2-5, Cols:6-9)`.
*   **2. Loop**
    *   From **Variables**, set `key` to `Read Key`.
    *   From **Logic**, drag `if [key] != [null]`. (Did someone press something?).
    *   **Then**:
        *   From **Text**, drag `print [key]`.
    *   Wait 0.1s.

### 9️⃣ Execution Flow (Plain English)
The Pico quickly scans Row 1, Row 2... looking for a connection to a Column. If found, it figures out which button (e.g., Row 1 + Col 1 = "1").

### 🔟 Generated Code (Reference Only)
```python
# Libraries required
from machine import Pin
# ... Matrix scanning code ...
key = keypad.get_key()
if key:
    print(key)
```

### 1️⃣1️⃣ Common Mistakes & Debug Tips
*   **Sticky Keys**: If a key prints repeatedly, increase the debounce/wait time.
*   **Wiring Order**: The pins are usually straight 1-8. If your "1" prints "4", the wires are reversed or rotated.

### 1️⃣2️⃣ Try This Next
*   **LCD**: Show the key on the screen instead of the console.

## 1️⃣ Project 0152: Password Entry System

### 2️⃣ Learning Objective
Collect multiple key presses to form a string ("1234").

### 3️⃣ Concepts Introduced
*   **String Appending**: `Password` = `Password` + `New Key`.

### 4️⃣ Hardware Required
*   **Pico**
*   **Keypad**
*   **Red/Green LEDs**

### 5️⃣ Wiring / Interfaces
*(Keypad GP2-9, Red GP14, Grn GP15)*

### 6️⃣ Blocks Used
🔹 **Text Join**
🔹 **If / Else**

### 7️⃣ Variables & State
*   **entered_code** (Text)
*   **key**

### 8️⃣ Step-by-Step Guide
*   **1. Setup**
    *   Set `entered_code` to "" (Empty).
*   **2. Loop**
    *   `key` = Read Key.
    *   **IF Key Pressed**:
        *   **Check Enter**:
            *   From **Logic**, drag `if [key] = ["#"]`.
            *   **Then (Check Password)**:
                *   IF `entered_code` == "1234": Turn Green ON.
                *   ELSE: Turn Red ON.
                *   Set `entered_code` = "". (Reset).
            *   **Else (Just a number)**:
                *   Set `entered_code` = `entered_code` + `key`.
                *   Print `entered_code` (Debug).

### 9️⃣ Execution Flow (Plain English)
Type "1", code becomes "1". Type "2", code becomes "12". Type "#", it checks if "12" == "1234". Fails -> Red Light.

### 🔟 Generated Code (Reference Only)
```python
if key == '#':
    if code == "1234": unlock()
    else: lock()
    code = ""
else:
    code += key
```

### 1️⃣1️⃣ Common Mistakes & Debug Tips
*   **Feedback**: Blink an LED every time a key is pressed so the user knows it worked.

### 1️⃣2️⃣ Try This Next
*   **Clear**: Use "*" to clear the typo without submitting.

## 1️⃣ Project 0153: Calculator Interface

### 2️⃣ Learning Objective
Use the keypad to perform math inputs.

### 3️⃣ Concepts Introduced
*   **Parsing**: Converting Text "5" to Number 5.
*   **States**: Input 1 -> Operator -> Input 2.

### 4️⃣ Hardware Required
*   **Pico**
*   **Keypad**

### 5️⃣ Wiring / Interfaces
*(Standard)*

### 6️⃣ Blocks Used
🔹 **Math (+)**
🔹 **Variables**

### 7️⃣ Variables & State
*   **num1**, **num2**, **op**

### 8️⃣ Step-by-Step Guide
*   **1. Loop**
    *   `key` = Keypad Read.
    *   IF `key` is `0-9`:
        *   Add to `current_string`.
    *   IF `key` is `A` (+):
        *   `num1` = `current_string`.
        *   `op` = "+".
        *   `current_string` = "".
    *   IF `key` is `B` (=):
        *   `num2` = `current_string`.
        *   Print `num1` + `num2`.
        *   `current_string` = "".

### 9️⃣ Execution Flow (Plain English)
User types "10". Clicks A (+). Logic saves 10. User types "5". Clicks B (=). Logic adds 10+5 and prints "15".

### 🔟 Generated Code (Reference Only)
```python
# Simplified
if key == 'A':
    mem = int(buffer)
    buffer = ""
elif key == 'B':
    res = mem + int(buffer)
    print(res)
```

### 1️⃣1️⃣ Common Mistakes & Debug Tips
*   **Crash**: If you press "=" before typing numbers, `int("")` causes an error. Need strict checks.

## 1️⃣ Project 0156: T9 Text Entry

### 2️⃣ Learning Objective
Type text on a number pad (Old School SMS).

### 3️⃣ Concepts Introduced
*   **Multi-Tap**: Press '2' once for 'A', twice for 'B'.

### 4️⃣ Hardware Required
*   **Pico**
*   **Keypad**

### 5️⃣ Wiring / Interfaces
*(Standard)*

### 6️⃣ Blocks Used
🔹 **Timer**
🔹 **Variables**

### 7️⃣ Variables & State
*   **last_key**, **press_count**

### 8️⃣ Step-by-Step Guide
*   **1. Loop**
    *   `new_key` = Read Key.
    *   IF `new_key` == `last_key` (Same button):
        *   `press_count` += 1.
    *   ELSE (New button):
        *   Resolve Letter (e.g. 2, count 1 -> 'A'. 2, count 2 -> 'B').
        *   Print Letter.
        *   `last_key` = `new_key`.
        *   `press_count` = 1.

### 9️⃣ Execution Flow (Plain English)
Logic to cycle through letters. 2 -> A -> B -> C -> 2.

### 🔟 Generated Code (Reference Only)
```python
# T9 Logic is surprisingly complex for blocks
# Simplified: Just explicit IFs
if key == '2':
    if count == 1: print("A")
    if count == 2: print("B")
```

### 1️⃣1️⃣ Common Mistakes & Debug Tips
*   **Timing**: T9 usually has a "timeout" (wait 1s to accept 'A').

## 1️⃣ Project 0160: Mastering Matrix (Debounce)

### 2️⃣ Learning Objective
Write your own scanner instead of using the library, to understand HOW it works.

### 3️⃣ Concepts Introduced
*   **Scanning Algorithm**: Power Row 1, Check Cols. Power Row 2, Check Cols...

### 4️⃣ Hardware Required
*   **Pico**
*   **Keypad**

### 5️⃣ Wiring / Interfaces
*(Standard)*

### 6️⃣ Blocks Used
🔹 **Digital Write**
🔹 **Digital Read**

### 7️⃣ Variables & State
*   **r**, **c**

### 8️⃣ Step-by-Step Guide
*   **1. Loop**
    *   **Scan Row 1**:
        *   Set Pin GP2 (Row 1) High. All other Rows Low.
        *   IF GP6 (Col 1) is High: Key is "1".
        *   IF GP7 (Col 2) is High: Key is "2".
    *   **Scan Row 2**:
        *   Set GP3 High... Check Cols.
    *   (Repeat for all 4 rows).

### 9️⃣ Execution Flow (Plain English)
This is exactly what the library does invisibly. We manually strobe the rows and sniff the columns.

### 🔟 Generated Code (Reference Only)
```python
mid = [2,3,4,5]
cols = [6,7,8,9]
for r in rows:
    r.value(1)
    if c1.value(): print(key_map[r][c1])
    r.value(0)
```

### 1️⃣1️⃣ Common Mistakes & Debug Tips
*   **Ghosting**: If you press two keys at once, current flow can get weird. Diodes are needed for full "N-Key Rollover", but simple keypads don't have them.

### 1️⃣2️⃣ Try This Next
*   **Chorded Keyboard**: Using combinations (1+2 pressed together) to mean something else.
