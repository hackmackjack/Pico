# Batch 71: Digital Art 4 (3-5 (Elementary))

## 1. Project 0701: Introduction to Digital Art

### 2. Learning Objective
Learn how to define colors using variables and cycle through them to create a simple looping pattern on an RGB LED.

### 3. Concepts Introduced
*   **RGB Color Model**: Mixing Red, Green, and Blue (0-255).
*   **Tuples**: Storing multiple values in one variable `(r, g, b)`.
*   **Variables**: Reusing defined colors.

### 4. Hardware Required
*   **Raspberry Pi Pico**
*   **RGB LED** (or NeoPixel)

### 5. Wiring / Interfaces
| Component | Pico Pin |
| :--- | :--- |
| **RGB LED Data/Red** | GP15 |
| **Green** | GP14 |
| **Blue** | GP13 |
*(Assuming Common Cathode RGB for PWM, or GP15 for NeoPixel Data)*

### 6. Blocks Used
*   **from Variables, drag `variables_set`** (set item to)
*   **from Loops, drag `pico_forever`** (forever do)
*   **from Smart IO, drag `pico_set_rgb`** (set RGB Color)
*   **from Smart IO, drag `pico_wait`** (wait)

### 7. Variables
*   **C1**, **C2**, **C3** (Color Tuples)

### 8. Step-by-Step Guide

**A. Initialization**
1.  **Define Colors**:
    *   Create variable `C1`. Set to `(255, 0, 0)` (Red).
    *   Create variable `C2`. Set to `(0, 255, 0)` (Green).
    *   Create variable `C3`. Set to `(0, 0, 255)` (Blue).

**B. Main Loop**
2.  **Cycle**:
    *   In `forever` loop:
    *   Set RGB LED to `C1`. Wait 1s.
    *   Set RGB LED to `C2`. Wait 1s.
    *   Set RGB LED to `C3`. Wait 1s.

### 9. Execution Flow
1.  **Setup**: Stores color codes in memory.
2.  **Loop**: Changes LED color every second.

### 10. Generated Code
``python
from machine import Pin, PWM
import time

# Simple PWM RGB implementation
red = PWM(Pin(15)); red.freq(1000)
grn = PWM(Pin(14)); grn.freq(1000)
blu = PWM(Pin(13)); blu.freq(1000)

C1 = (65535, 0, 0) # MicroPython PWM is 16-bit
C2 = (0, 65535, 0)
C3 = (0, 0, 65535)

while True:
    # Red
    red.duty_u16(C1[0]); grn.duty_u16(C1[1]); blu.duty_u16(C1[2])
    time.sleep(1)
    # Green
    red.duty_u16(C2[0]); grn.duty_u16(C2[1]); blu.duty_u16(C2[2])
    time.sleep(1)
    # Blue
    red.duty_u16(C3[0]); grn.duty_u16(C3[1]); blu.duty_u16(C3[2])
    time.sleep(1)
``

### 11. Common Mistakes
*   **Common Anode vs Cathode**: If the LED is "Common Anode", logic is inverted (0 is Bright, 65535 is Off).
*   **Wiring**: Mixing up R, G, and B pins.

### 12. Try This Next
*   **Faster**: Cycle every 0.1s.
*   **Mix**: Create `C4 = (255, 255, 0)` (Yellow).

### 3. Concepts Introduced

*   **Visual Impact**: How brightness perception works with short flashes.

### 4. Hardware Required
*   **Raspberry Pi Pico**
*   **RGB LED**

### 5. Wiring / Interfaces
| Component | Pico Pin |

| **RGB LED** | GP13, GP14, GP15 |

### 6. Blocks Used

*   **from Smart IO, drag `pico_set_rgb`**
*   **from Smart IO, drag `pico_wait`**

### 7. Variables
*   None

### 8. Step-by-Step Guide

**A. Loop**
1.  **Flash**:
    *   Set RGB to **White** (255, 255, 255).
    *   Wait **0.1s**.
2.  **Rest**:
    *   Set RGB to **Black** (0, 0, 0).
    *   Wait **5.0s**.

### 9. Execution Flow
1.  **Flash**: Brief burst of light.
2.  **Darkness**: Long pause.
3.  **Repeat**: Like a camera flash or warning beacon.

### 10. Generated Code
``python
from machine import Pin, PWM
import time

# Setup PWM...
r = PWM(Pin(15)); g = PWM(Pin(14)); b = PWM(Pin(13))
for p in [r,g,b]: p.freq(1000)

while True:
    # ON (White)
    r.duty_u16(65535); g.duty_u16(65535); b.duty_u16(65535)
    time.sleep(0.1)
    # OFF
    r.duty_u16(0); g.duty_u16(0); b.duty_u16(0)
    time.sleep(5)
``

### 11. Common Mistakes
*   **Too Short**: < 0.05s might be missed by the eye if the LED has capacitance.
*   **Seizure Warning**: Don't make the OFF time too short.

### 12. Try This Next

## 1. Project 0710: Mastering Digital Art (Gamma)

### 2. Learning Objective
Apply Gamma Correction. The human eye sees brightness logarithmically, but LEDs brighten linearly. We fix this with math.

### 3. Concepts Introduced
*   **Gamma Curve**: `Input ^ 2.2`.
*   **Perception**: Biology of the eye.

### 4. Hardware Required
*   **Pico**
*   **RGB LED**

### 5. Wiring / Interfaces
| Component | Pico Pin |
| :--- | :--- |
| **RGB LED** | GP13-15 |

### 6. Blocks Used
*   **from Math, drag `math_pow`**

### 7. Variables
*   **gamma_val**

### 8. Step-by-Step Guide

1.  **Raw Ramp**: 0 to 255.
2.  **Correct**: `corrected = (raw / 255) ^ 2.2 * 255`.
3.  **Output**: Set PWM.

### 9. Execution Flow
1.  **Result**: The fade looks "smooth" to the human eye, instead of rushing to bright and stalling.

### 10. Generated Code
``python
gamma = 2.2
val_norm = raw / 255.0
corrected = int(pow(val_norm, gamma) * 65535)
pwm.duty_u16(corrected)
``

### 11. Common Mistakes
*   **Integer Math**: Doing `raw/255` in integer arithmetic yields 0.

### 12. Try This Next
*   **Comparison**: Run one LED linear, one gamma corrected side-by-side.

## 1. Project 0800: Advanced Advanced Infrared Remote Prototype

### 2. Learning Objective
IR Lock. Unlock a servo only if correct sequence (1-2-3-4) is entered.

### 3. Concepts Introduced
*   **State Machine**: Password Logic (State 0->1->2->3->Unlock).
*   **Security**: Sequence validation.

### 4. Hardware Required
*   **Pico**, **IR**, **Servo**

### 5. Wiring / Interfaces
*   Standard

### 6. Blocks Used
*   **from Logic, drag `controls_if`**

### 7. Variables
*   **stage**

### 8. Step-by-Step Guide

1.  **Rx**.
2.  **Check**:
    *   If `stage==0` and `code==1`: `stage=1`.
    *   Else If `stage==1` and `code==2`: `stage=2`...
    *   Else: `stage=0` (Reset on wrong key).
3.  **Unlock**: If `stage==4`: Open Servo.

### 9. Execution Flow
1.  **Enter**: 1... 2... 3... 4.
2.  **Success**: Door opens.
3.  **Fail**: 1... 2... 5. Reset.

### 10. Generated Code
``python
state = 0
sequence = [1, 2, 3, 4]
if key == sequence[state]:
    state += 1
    if state == 4: unlock()
else:
    state = 0
``

### 11. Common Mistakes
*   **Feedback**: Don't blink "Correct" after every key, it makes guessing easy. Only feedback at end.
