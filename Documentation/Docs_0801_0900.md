## 1. Project 801: Advanced Keypad Security Sensor Setup

### 2. Learning Objective
Learn to interface a 4x4 Matrix Keypad. Understand how to "scan" rows and columns to detect key presses using nested loops.

### 3. Concepts Introduced
*   **Matrix Scanning**: Reading 16 buttons using only 8 pins (4 Rows + 4 Columns).
*   **Nested Loops**: Using a loop inside a loop (`for` inside `for`) to iterate through a grid.
*   **Pull-Down Resistors**: Keeping input pins Low when no button is pressed.

### 4. Hardware Required
*   **Raspberry Pi Pico**
*   **4x4 Membrane Keypad**

### 5. Wiring / Interfaces
*   **Rows (R1-R4)** -> GP2, GP3, GP4, GP5
*   **Cols (C1-C4)** -> GP6, GP7, GP8, GP9

### 6. Blocks Used
*   **from Pins, drag `set_pin`**
*   **from Control, drag `for_loop`**

### 7. Variables
*   **key_pressed** (String)
*   **rows** (List of Pins)
*   **cols** (List of Pins)

### 8. Step-by-Step Guide
1.  **Configure Rows**: Set Rows as **Output**. Set all to Low initially.
2.  **Configure Cols**: Set Columns as **Input** with **Pull-Down**.
3.  **Scan Loop**:
    *   Set Row 1 High.
    *   Check Col 1, Col 2, Col 3, Col 4.
    *   If Col 1 is High, then Button (1,1) is pressed.
    *   Set Row 1 Low.
    *   Repeat for Row 2, 3, 4.

### 9. Execution Flow
1.  **Start**: System enters infinite loop.
2.  **Pulse**: Pico sends voltage to Row 1.
3.  **Check**: Pico reads Columns. If you press '1', voltage flows from Row 1 to Col 1.
4.  **Detect**: Pico sees Col 1 High -> Prints "1".

### 10. Generated Code
``python
import machine
import utime

# Wiring: R1-R4 on 2-5, C1-C4 on 6-9
rows = [machine.Pin(i, machine.Pin.OUT) for i in range(2, 6)]
cols = [machine.Pin(i, machine.Pin.IN, machine.Pin.PULL_DOWN) for i in range(6, 10)]

keys = [
    ['1', '2', '3', 'A'],
    ['4', '5', '6', 'B'],
    ['7', '8', '9', 'C'],
    ['*', '0', '#', 'D']
]

def scan_keypad():
    for r in range(4):
        rows[r].value(1) # Power the row
        for c in range(4):
            if cols[c].value() == 1:
                # Key Detected
                rows[r].value(0) # Reset before return
                return keys[r][c]
        rows[r].value(0) # Turn row off
    return None

while True:
    key = scan_keypad()
    if key:
        print(f"Key: {key}")
        utime.sleep(0.2) # Simple debounce
``

### 11. Common Mistakes
*   **Wrong Pin Mode**: If Columns are not Pulled Down, they will float random values.
*   **Short Circuit**: If you press two buttons in the same column but different rows, you might short High Row to Low Row. (Series resistors recommended for safety).

### 12. Try This Next
*   **Speed**: How fast can you type?
*   **Tone**: Beep a buzzer every time a key is pressed.

## 1. Project 803: Advanced Keypad Security Threshold Logic

### 2. Learning Objective
Implement robust input handling with "Debouncing" and "Edge Detection". Ignore accidental double-presses and keys held down too long.

### 3. Concepts Introduced
*   **Debounce**: Waiting for the mechanical contacts to settle (stop bouncing) before reading.
*   **Edge Detection**: Triggering an action only when the key state changes from Released to Pressed.
*   **Rate Limiting**: Preventing rapid-fire inputs.

### 4. Hardware Required
*   **Raspberry Pi Pico**
*   **Keypad**

### 5. Wiring / Interfaces
*   **Keypad** -> GP2-GP9

### 6. Blocks Used
*   **from Smart IO, drag `ticks_ms`**
*   **from Logic, drag `if`**

### 7. Variables
*   **last_key_time** (Number)
*   **current_key_state** (Boolean)

### 8. Step-by-Step Guide
1.  **Global Timer**: `last_press = 0`.
2.  **Scan**: Get current key.
3.  **Check Time**: `if (now - last_press) > 200ms`:
    *   **Accept Key**.
    *   `last_press = now`.
4.  **Else**: Ignore key (it's bounce or repeat).

### 9. Execution Flow
1.  **Press**: User hits '5'. Contacts bounce (High-Low-High) for 5ms.
2.  **Logic**: Reads first High. Sets timer. 
3.  **Bounce**: Next High comes 2ms later. Logic sees `time < 200`. Ignores it.
4.  **Result**: Single clean '5' registered.

### 10. Generated Code
``python
last_press_time = 0
debounce_delay = 200 # ms

while True:
    key = scan_keypad()
    if key:
        now = utime.ticks_ms()
        if utime.ticks_diff(now, last_press_time) > debounce_delay:
            last_press_time = now
            print(f"Accepted: {key}")
            # Key "Held" logic would need state tracking
        else:
            # Ignored (Too fast)
            pass
``

### 11. Common Mistakes
*   **Too Slow**: If delay is 1000ms, user cannot type "123" quickly. 200ms is a sweet spot.
*   **Blocking**: Using `sleep(0.2)` works but freezes the whole Pico. `ticks_ms()` is non-blocking (better).

### 12. Try This Next
*   **Hold**: Detect if a key is held for 2 seconds (e.g., to enter Programming Mode).
*   **Typematic**: Allow repeat if held for > 1s (like a computer keyboard).

## 1. Project 804: Advanced Keypad Security Status Monitor

### 2. Learning Objective
Visualize system status (Locked/Unlocked) using LEDs. Update the visual state immediately upon authorized input.

### 3. Concepts Introduced
*   **State Machine**: The system is either in state `LOCKED` or `UNLOCKED`.
*   **Transition**: An event (Keypress) causes a state change.
*   **Feedback**: Immediate visual confirmation of state.

### 4. Hardware Required
*   **Raspberry Pi Pico**
*   **Keypad**
*   **Red LED** (Locked)
*   **Green LED** (Unlocked)

### 5. Wiring / Interfaces
*   **Red LED** -> GP16
*   **Green LED** -> GP17

### 6. Blocks Used
*   **from Pins, drag `set_output`**
*   **from Control, drag `if_else`**

### 7. Variables
*   **is_locked** (Boolean)

### 8. Step-by-Step Guide
1.  **Setup**: `is_locked = True`. Turn Red On.
2.  **Loop**: Check Key.
3.  **Logic**:
    *   If Key `*` -> `is_locked = True`.
    *   If Key `#` -> `is_locked = False`.
4.  **Update LEDs**:
    *   If `is_locked`: Red ON, Green OFF.
    *   Else: Green ON, Red OFF.

### 9. Execution Flow
1.  **Boot**: Red LED is ON. (Secure).
2.  **Action**: User presses `#`.
3.  **Change**: Green LED turns ON. Red OFF.
4.  **Action**: User presses `*`.
5.  **Change**: System re-locks. Red ON.

### 10. Generated Code
``python
red = machine.Pin(16, machine.Pin.OUT)
grn = machine.Pin(17, machine.Pin.OUT)

is_locked = True

def update_leds():
    if is_locked:
        red.value(1)
        grn.value(0)
    else:
        red.value(0)
        grn.value(1)

update_leds()

while True:
    key = scan_keypad()
    if key:
        if key == '*':
            is_locked = True
            print("System Locked")
        elif key == '#':
            is_locked = False
            print("System Unlocked")
        update_leds()
        utime.sleep(0.2)
``

### 11. Common Mistakes
*   **Undefined State**: Failing to set an initial state (both LEDs off). Always default to "Locked" (Fail-Secure).
*   **Flicker**: Updating lines 1000 times a second can cause dimming if using PWM. With simple GPIO, it's fine.

### 3. Concepts Introduced

*   **Access Control**: Granting access only on match.
*   **Actuation**: Moving a motor to simulate a bolt unlocking.

### 4. Hardware Required

*   **from Motion & Motors, drag `servo_write`**

*   **password** (String)
*   **correct_pass** (String)

### 8. Step-by-Step Guide
1.  **Set Pass**: `correct = "1234"`.
2.  **Collect**: Accumulate keys into `buffer`.
3.  **Submit**: On `#` press:
    *   If `buffer == correct`:
        *   Servo -> 90 degrees (Open).
        *   Green LED.
    *   Else:
        *   Flash Red LED 3 times.
        *   Servo -> 0 (Stay Closed).

### 9. Execution Flow
1.  **User**: Types `1... 2... 3... 4... #`.
2.  **Check**: Match!
3.  **Action**: Servo buzzes and arm rotates. Door opens.
4.  **User**: Types `9... 9... #`.
5.  **Action**: Red LED flashes. Servo stays still.

### 10. Generated Code
``python
pwm = machine.PWM(machine.Pin(18))
pwm.freq(50)

def set_servo(angle):
    # Map 0-180 to duty 1000-9000 (approx)
    duty = int(1000 + (angle/180) * 8000)
    pwm.duty_u16(duty)

correct_pass = "1234"
entry = ""
set_servo(0) # Lock

while True:
    key = scan_keypad()
    if key:
        if key == '#':
            if entry == correct_pass:
                print("Access Granted")
                grn.value(1)
                set_servo(90)
                utime.sleep(3)
                set_servo(0) # Auto-lock
                grn.value(0)
            else:
                print("Access Denied")
                for _ in range(3):
                    red.toggle()
                    utime.sleep(0.2)
            entry = ""
        else:
            entry += key
        utime.sleep(0.2)
``

### 11. Common Mistakes
*   **Hardcoding**: Storing passwords in plain text is fine for a toy, bad for a bank.
*   **Servo Power**: Servos draw a lot of current. Powering from Pico's 3.3V might reset the board. Use VBUS (5V).

## 1. Project 806: Advanced Keypad Security Safety Trigger

### 2. Learning Objective
Implement "Brute Force Protection". If an attacker guesses wrong too many times, lock them out completely for a duration.

### 3. Concepts Introduced
*   **Failure Counter**: Increments on wrong password.
*   **Timeout/Backoff**: Disabling input for a set time (Cost).
*   **Security Policy**: "3 strikes and you're out".

### 4. Hardware Required
*   **Raspberry Pi Pico**
*   **Keypad**
*   **Buzzer**

### 5. Wiring / Interfaces
*   **Buzzer** -> GP19

### 6. Blocks Used
*   **from Control, drag `wait`**
*   **from Variables, drag `change_by`**

### 7. Variables
*   **fail_count** (Number)

### 8. Step-by-Step Guide
1.  **Init**: `fails = 0`.
2.  **Verify**: On wrong password:
    *   `fails += 1`.
    *   If `fails >= 3`:
        *   Print "Locked for 5 minutes".
        *   Siren Sound.
        *   `sleep(300)` (Simulate 5 mins with 5 secs for demo).
        *   `fails = 0`.

### 9. Execution Flow
1.  **Attacker**: Tries `0000`. Denied.
2.  **Attacker**: Tries `0001`. Denied.
3.  **Attacker**: Tries `0002`. Denied.
4.  **System & Storage**: "ALARM!". Keypad stops responding.
5.  **Attacker**: Can't try `0003` until timer expires.

### 10. Generated Code
``python
fail_count = 0
buzzer = machine.Pin(19, machine.Pin.OUT)

while True:
    # ... inside check logic ...
    # if wrong:
    fail_count += 1
    print(f"Wrong! Attempts: {fail_count}/3")
    
    if fail_count >= 3:
        print("SECURITY LOCKOUT")
        buzzer.value(1)
        utime.sleep(1)
        buzzer.value(0)
        # Lockout loop
        for i in range(10): # 10 seconds demo
            red.toggle()
            utime.sleep(0.5)
        fail_count = 0
        print("System Ready")
``

### 11. Common Mistakes
*   **Reset on Reboot**: An attacker can just unplug the Pico to reset the counter. True security needs non-volatile storage (Flash).
*   **Denial of Service**: If a prankster locks the keypad, the real owner also can't get in.

### 12. Try This Next
*   **Exponential Backoff**: 1st lock = 10s. 2nd lock = 1 min. 3rd lock = 1 hour.
*   **Master Key**: A specific "Admin Key" (e.g., 9999) bypasses the lock.

## 1. Project 810: Advanced Advanced Keypad Security Prototype

### 2. Learning Objective
Implement a "Rolling Code" or One-Time Password (OTP) system. The password changes after every successful use to prevent replay attacks.

### 3. Concepts Introduced
*   **OTP (One Time Password)**: A code that is valid for only one session.
*   **Code Generation**: Creating a predictable sequence (e.g., +1111) or random list.
*   **Session State**: Tracking which code is currently valid.

### 4. Hardware Required
*   **Raspberry Pi Pico**
*   **Keypad**

### 5. Wiring / Interfaces
*   **Keypad** -> GP2-GP9

### 6. Blocks Used
*   **from Lists, drag `get_item`**
*   **from Variables, drag `increment`**

### 7. Variables
*   **code_list** (List)
*   **current_index** (Number)

### 8. Step-by-Step Guide
1.  **List**: `codes = ["1111", "2222", "3333"]`.
2.  **Index**: `idx = 0`.
3.  **Check**:
    *   Require `input == codes[idx]`.
4.  **On Success**:
    *   Unlock.
    *   `idx += 1`.
    *   Print "Next Code Required: " + `codes[idx]`.

### 9. Execution Flow
1.  **User**: "1111". **Success**.
2.  **User**: "1111". **Fail** (Code expired).
3.  **User**: "2222". **Success**.
4.  **Security**: Even if someone watched you type "1111", that code is now useless.

### 10. Generated Code
``python
otp_codes = ["1111", "5678", "4321", "9999"]
token_index = 0

print(f"DEBUG: Current Code is {otp_codes[token_index]}")

while True:
    # ... scan and get # ...
    if key == '#':
        if entry == otp_codes[token_index]:
            print("Unlocked!")
            token_index = (token_index + 1) % len(otp_codes)
            print(f"Code Used. Next one required.")
        else:
            print("Invalid Code")
``

### 11. Common Mistakes
*   **Out of Index**: If user uses all codes, the script crashes. Use modulo `%` to wrap around or deny access.
*   **Sync**: If the user forgets the next code, they are locked out forever. (Real RSA keys use time-based algorithms to avoid this).

### 12. Try This Next
*   **Math Gen**: Instead of a list, `next_code = current_code + 123`.
*   **Time Based**: Code changes every 60 seconds (TOTP).

*   **Deadzone**: A software filter to ignore small movements near the center.
*   **Noise**: Jitter in electrical signals.

### 4. Hardware Required
*   **Raspberry Pi Pico**
*   **Analog Joystick Module**

### 5. Wiring / Interfaces
*   **VRx** -> GP26 (ADC0)
*   **VRy** -> GP27 (ADC1)
*   **SW** -> GP16 (Digital Button)

### 6. Blocks Used
*   **from Smart Sensors, drag `read_analog`**
*   **from Logic, drag `if_else`**

### 7. Variables
*   **x_val** (Number)
*   **y_val** (Number)

### 8. Step-by-Step Guide
1.  **Read Raw**: Read ADC0 (X) and ADC1 (Y).
2.  **Print**: Output values (approx 32768 in center).
3.  **Deadzone Logic**:
    *   `if val > 30000 and val < 35000`: `val = 0` (or `center`).
    *   Else: `val = measured`.

### 9. Execution Flow
1.  **Idle**: Stick at center. Application prints "X: 0, Y: 0".
2.  **Move**: User pushes stick Up.
3.  **Change**: Y value increases to 65535.
4.  **Release**: Y drops back to ~32768 (0).

### 10. Generated Code
``python
import machine
import utime

x_axis = machine.ADC(26)
y_axis = machine.ADC(27)
sw = machine.Pin(16, machine.Pin.IN, machine.Pin.PULL_UP)

def get_normalized(adc):
    raw = adc.read_u16()
    # Deadzone 30k - 35k
    if raw > 30000 and raw < 36000:
        return 0
    else:
        # Shift so center is 0. Up is +32k, Down is -32k
        return raw - 32768

while True:
    x = get_normalized(x_axis)
    y = get_normalized(y_axis)
    btn = sw.value()
    print(f"X: {x}, Y: {y}, Click: {btn}")
    utime.sleep(0.1)
``

### 11. Common Mistakes
*   **Logarithmic Pot**: Some joysticks use audio pots (logarithmic curve), making them very sensitive at one end. Linear is required.
*   **Floating**: If VRx is not connected, the value will fluctuate wildly (Ghost input).

### 12. Try This Next
*   **Invert**: Make Up negative and Down positive.
*   **Scale**: Map 0-65535 to 0-100 percentage.

def drive(speed):
    # speed: -100 to 100
    duty = int(abs(speed) * 65535 / 100)
    
    if speed > 0:

        ib.duty_u16(0)
    elif speed < 0:
        ia.duty_u16(0)
        ib.duty_u16(duty)
    else:
        ia.duty_u16(0)
        ib.duty_u16(0)

# Test Sweep

    drive(s)
    utime.sleep(0.1)
``

### 11. Common Mistakes

*   **Both PWM**: If you set IA=50% and IB=50%, the net voltage is 0. Both High = Brake.

## 1. Project 823: Advanced Motor Driver (L9110) Threshold Logic

### 2. Learning Objective

### 3. Concepts Introduced

*   **Deadband Remapping**: Translating 1-100 request to 20-100 output.
*   **Remap Function**: `out = low2 + (val - low1) * ...`.

### 4. Hardware Required
*   **Raspberry Pi Pico**

### 5. Wiring / Interfaces

### 6. Blocks Used

### 7. Variables

*   **actual_speed** (Number)

### 8. Step-by-Step Guide
1.  **Input**: Receive `req` (0-100).
2.  **Filter**:
    *   If `req == 0` -> `act = 0`.
    *   If `req > 0` -> `act = map(req, 1, 100, 20, 100)`.
3.  **Result**: 1% input becomes 20% output (enough to spin).

*   **Magnetic Actuation**: Non-contact switching.
*   **Pull-Up Logic**: Connect one side to Ground, other side to Pin with Pull-Up.
*   **NO vs NC**: Normally Open (Standard) vs Normally Closed.

### 4. Hardware Required
*   **Raspberry Pi Pico**
*   **Reed Switch**
*   **Magnet**

### 5. Wiring / Interfaces
*   **Pin 1** -> GP16
*   **Pin 2** -> GND

### 6. Blocks Used

### 7. Variables
*   **door_state** (Number)

### 8. Step-by-Step Guide
1.  **Config**: GP16 Input + PullUp.
2.  **Read**: `val = pin.value()`.
3.  **Print**: If 0 -> "Closed (Magnet Near)". If 1 -> "Open".

### 9. Execution Flow
1.  **Magnet Away**: Pin floats high (1). Print "Open".
2.  **Magnet Near**: Pin grounded (0). Print "Closed".

### 10. Generated Code
``python

import utime

# Pull-Up is crucial because switch connects to Ground

    else:

### 7. Variables

### 8. Step-by-Step Guide
1.  **Wait**: For Edge (High->Low).
2.  **Measure**: `dt = Now - Last_Time`.
3.  **Calc**: `RPM = 60000 / dt_ms`.
4.  **Save**: `Last_Time = Now`.

### 9. Execution Flow
1.  **Spin**: Wheel spins. Magnet passes switch.
2.  **Pulse**: 100ms interval.
3.  **Calc**: 60000 / 100 = 600 RPM.

### 10. Generated Code
``python
last_pulse = utime.ticks_ms()

while True:
    # Wait for Open->Closed
    while door_sensor.value() == 1: pass
    
    now = utime.ticks_ms()
    dt = utime.ticks_diff(now, last_pulse)
    last_pulse = now
    
    if dt > 0:
        rpm = 60000 / dt
        print(f"RPM: {int(rpm)}")
    
    # Wait for Closed->Open (prevent double count)
    while door_sensor.value() == 0: pass
``

### 6. Blocks Used

### 7. Variables
*   **shake_count** (Number)

### 8. Step-by-Step Guide
1.  **Wait**: For `shake_count > 5` inside 1s.
2.  **Detect Stop**: When `shake_count` drops to 0.
3.  **Action**: `num = random(1, 6)`. Print `num`.

### 9. Execution Flow
1.  **Idle**: "Shake me!".
2.  **Action**: *Rattle Rattle*.
3.  **Stop**: "Rolling... You got 5!".

### 10. Generated Code
``python
import random

changes = 0
last_v = 0
print("Shake to Roll!")

while True:
    # Count shakes in 100ms window
    curr = tilt.value()
    if curr != last_v:
        changes += 1
        last_v = curr
        
    # Decay changes
    if changes > 0:
        # If we were shaking effectively...
        if changes > 5:
            print("Rolling...", end="\r")
            while tilt.value() != last_v: # Wait for settle
                 last_v = tilt.value()
                 utime.sleep(0.1)
            
            # Shaking stopped
            print(f"Result: {random.randint(1, 6)}   ")
            changes = 0
            utime.sleep(2) # Show result
            print("Shake again!")
    
    utime.sleep(0.05)
``
