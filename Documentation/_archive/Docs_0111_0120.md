
# 🏁 Batch 12: Analog Sensors 1 (Potentiometer)

## 1️⃣ Project 0111: Read Potentiometer Value (Serial)

### 2️⃣ Learning Objective
Learn to read a variable voltage. Unlike buttons (0 or 1), a potentiometer (pot) gives a range of values (0 to 65535). You will print this value to the computer.

### 3️⃣ Concepts Introduced
*   **Analog to Digital Converter (ADC)**: The part of the Pico that measures voltage.
*   **Resolution**: 16-bit means 65,536 possible steps.

### 4️⃣ Hardware Required
*   **Pico**
*   **10kΩ Potentiometer** (Knob)

### 5️⃣ Wiring / Interfaces
| Component | Pico Pin |
| :--- | :--- |
| **Left Pin** | GND |
| **Right Pin** | 3.3V |
| **Middle Pin** | GP26 (ADC0) |

### 6️⃣ Blocks Used
🔹 **Read Analog**
*   **Category:** Pin Access
*   **Block:** `read analog pin [26]`
🔹 **Print**

### 7️⃣ Variables & State
*   **pot_value**

### 8️⃣ Step-by-Step Guide
*   **1. Loop**
    *   From **Pin Access**, drag `read analog pin [26]`.
    *   From **Text**, drag `print [message]`.
    *   Snap the read block into the print block.
    *   From **Timing**, drag `sleep 0.1 seconds`.

### 9️⃣ Execution Flow (Plain English)
The knob acts like a voltage divider. Rotating it changes the voltage on GP26 from 0V to 3.3V. The Pico measures this and prints a number (0 = 0V, 65535 = 3.3V).

### 🔟 Generated Code (Reference Only)
```python
import machine
import time
pot = machine.ADC(26)
while True:
    print(pot.read_u16())
    time.sleep(0.1)
```

### 1️⃣1️⃣ Common Mistakes & Debug Tips
*   **Floating**: If the numbers jump around wildly even when you don't touch it, check your Ground wire.
*   **Pin**: Only GP26, 27, and 28 are Analog pins. GP0 won't work.

### 1️⃣2️⃣ Try This Next
*   **Percentage**: Convert the range 0-65535 to 0-100%.

### 4️⃣ Hardware Required

*   **Potentiometer**
*   **LED**

### 5️⃣ Wiring / Interfaces
| Component | Pico Pin |
| :--- | :--- |

| **LED** | GP15 |

### 6️⃣ Blocks Used
🔹 **Analog Write** (PWM)

### 7️⃣ Variables & State
*   **val**

### 8️⃣ Step-by-Step Guide
*   **1. Loop**
    *   `val` = Read Analog GP26.
    *   From **Smart IO**, drag `Analog Write Pin [15] value [val]`.

### 9️⃣ Execution Flow (Plain English)
The ADC reads a high number (e.g. 50000). The PWM writes that same number to the LED duty cycle. High number = Bright light.

### 🔟 Generated Code (Reference Only)
```python
led = machine.PWM(machine.Pin(15))
pot = machine.ADC(26)
while True:
    val = pot.read_u16()
    led.duty_u16(val)
    time.sleep(0.01)
```

### 1️⃣1️⃣ Common Mistakes & Debug Tips
*   **Inverted**: If turning clockwise makes it darker, swap 3.3V and GND wires on the pot.

### 1️⃣2️⃣ Try This Next
*   **Inverse**: Make it so turning the knob UP dims the LED (Hint: `65535 - val`).

### 4️⃣ Hardware Required
*   **Pico**
*   **Potentiometer**
*   **LCD**

### 5️⃣ Wiring / Interfaces
*(Combine previous wiring)*

### 6️⃣ Blocks Used
🔹 **Math** (Multiply, Divide)
🔹 **LCD Print**

### 7️⃣ Variables & State
*   **raw**, **volts**

### 8️⃣ Step-by-Step Guide
*   **1. Loop**
    *   `raw` = Read AD26.
    *   `volts` = (`raw` / 65535) * 3.3.
    *   Clear LCD.
    *   Print "Voltage:" at Line 0.
    *   Print `volts` at Line 1.
    *   Wait 0.5s.

### 9️⃣ Execution Flow (Plain English)
We take the raw digital number and use math to reverse-calculate what voltage created it.

### 🔟 Generated Code (Reference Only)
```python

conversion_factor = 3.3 / 65535
while True:
    reading = adc.read_u16()

    lcd.clear()
    lcd.putstr("Voltage: {:.2f}V".format(volts))
    time.sleep(0.5)
```

### 1️⃣1️⃣ Common Mistakes & Debug Tips
*   **Max Voltage**: NEVER put more than 3.3V into the ADC. You will fry the Pico. No 9V batteries directly!

    *   **Logic**:

## 1️⃣ Project 0120: Mastering Analog Inputs (Smoothing)

### 2️⃣ Learning Objective
Fix "jittery" sensors using software averaging.

### 3️⃣ Concepts Introduced
*   **Signal Processing**: Noise reduction.
*   **Average**: Sum / Count.

### 4️⃣ Hardware Required
*   **Pico**
*   **Pot**

### 5️⃣ Wiring / Interfaces
*(Standard Pot setup)*

### 6️⃣ Blocks Used
🔹 **Repeat**
🔹 **Math (Add, Divide)**

### 7️⃣ Variables & State
*   **total**, **average**

### 8️⃣ Step-by-Step Guide
*   **1. Loop**
    *   Set `total` = 0.
    *   **Inner Loop (10 times)**:
        *   `reading` = Read Pot.
        *   `total` = `total` + `reading`.
        *   Wait 0.001s.
    *   `average` = `total` / 10.
    *   Print `average`.

### 9️⃣ Execution Flow (Plain English)
Instead of trusting one single measurement (which might be wrong due to electrical noise), we take 10 quick snapshots and find the middle ground. The output is much smoother and stable.

### 🔟 Generated Code (Reference Only)
```python
while True:
    total = 0
    for i in range(10):
        total += adc.read_u16()
        time.sleep(0.001)
    
    avg = total // 10
    print(avg)
```

### 1️⃣1️⃣ Common Mistakes & Debug Tips
*   **Overflow**: If you add too many big numbers (like 1000 measurements), the variable might get too big for a small microcontroller to handle (though Python handles big integers well, C++ does not).

### 1️⃣2️⃣ Try This Next
*   **Weighted Average**: NewValue = (OldValue * 0.9) + (NewSample * 0.1). This is a "Low Pass Filter".
