## 1. Project 1101: Advanced Servo Kinematics Sensor Setup

### 2. Learning Objective
"Torque Limiting". Protect a servo from burning out by monitoring its current draw. If the current spike exceeds a safety threshold (e.g., 500mA), automatically reduce the PWM duty cycle (torque) to relieve the load.

### 3. Concepts Introduced
*   **Active Circuit Protection**: Software fuses.
*   **Current Sensing**: Measuring load via shunt/ADC.
*   **Feedback Loops**: Modifying output based on input.

### 4. Hardware Required

*   **Servo Motor**

### 5. Wiring / Interfaces
| Component | Pico Pin | Notes |
| :--- | :--- | :--- |
| **Servo Signal** | GP0 | PWM Output |
| **Current Sense** | GP26 | ADC0 (Analog output from sensor) |

### 6. Blocks Used
*   From **Motion & Motors**, drag **`move_servo`**
*   From **Smart Sensors**, drag **`read_adc`**

### 7. Variables
*   **amps, current_pos, safe_mode**

### 8. Step-by-Step Guide
1.  **Initialize Hardware**:
    *   From **Motion & Motors**, drag **`init_servo`** block. Select pin **GP0**.
    *   From **Smart Sensors**, drag **`init_adc`** block. Select pin **GP26**.
    *   Create a variable `safe_mode` and set it to **False**.
2.  **Main Control Loop**:
    *   From **Loops**, drag **`while True`**.
    *   **Measure Load**:
        *   Read ADC value from Current Sensor.
        *   Convert raw reading to Milliamps (Logic depends on sensor sensitivity, e.g., 185mV/A).
        *   Store in variable `amps`.
    *   **Safety Check**:
        *   From **Logic**, drag **`if_else`** block.
        *   Condition: `amps > 500` (mA).
        *   **True (Overload)**:
            *   Set `safe_mode` to **True**.
            *   Print **"OVERLOAD! Reducing Power"**.
            *   Call **`servo_detach`** or set Duty Cycle to 0 to cut torque.
            *   Wait **2 seconds** for cool down.
        *   **False (Normal)**:
            *   If `safe_mode` was true, re-attach servo.
            *   Continue normal movement operations.
3.  **Testing**:
    *   Grab the servo horn to stall it manually. Watch the "Overload" message appear and the servo go limp.

### 9. Execution Flow
1.  **Normal**: Servo moves freely. Current ~100mA.
2.  **Stall**: User blocks arm. Current spikes to 800mA.
3.  **Protect**: System detects spike, cuts power. Arm goes limp.

### 10. Generated Code
``python
import machine
import utime

# Hardware Setup
servo = machine.PWM(machine.Pin(0))
servo.freq(50)
current_sense = machine.ADC(26)

# Calibration for ACS712 or similar (Vref 3.3V, Sensitivity let's say 1000 arbitrary scale)
# Real calculation: Voltage = (ADC / 65535) * 3.3
# Amps = (Voltage - Offset) / Sensitivity
# Simplified for logic demo:

SAFE_LIMIT_RAW = 10000 # Threshold raw value ~ 0.5V change

def set_angle(angle):
    # Map 0-180 to 1000-9000 duty
    duty = int(1000 + (angle/180) * 8000)
    servo.duty_u16(duty)

def cut_power():
    servo.duty_u16(0)

print("Torque Limiter Active")

while True:
    # 1. Read Load
    raw_current = current_sense.read_u16()
    
    # 2. Check Threshold
    if raw_current > SAFE_LIMIT_RAW:
        print(f"OVERLOAD DETECTED! (Val: {raw_current})")
        cut_power()
        utime.sleep(2) # Cooldown
        # Resume?
        print("Cooling done. Resuming.")
    else:
        # Sweep Test
        for i in range(0, 180, 10):
            set_angle(i)
            utime.sleep(0.05)
            # Check during move
            if current_sense.read_u16() > SAFE_LIMIT_RAW:
                 break 
        
    utime.sleep(0.1)
``

### 11. Common Mistakes
*   **Inductive Spikes**: Servos create noise on power lines. Use a separate power supply or big capacitor, otherwise the Pico might reset.
*   **ADC Noise**: The motor noise might trigger the ADC falsely. Average 10 readings.

## 1. Project 1102: Advanced Servo Kinematics Data Reader

### 2. Learning Objective
"Visual Path". Visualize Forward Kinematics. Calculate the X-Y coordinates of the servo arm's tip based on its angle and length, and draw this position on an OLED screen in real-time.

### 3. Concepts Introduced
*   **Forward Kinematics**: Converting Joint Angle ($\theta$) to Cartesian Position ($x, y$).
*   **Trigonometry**: Sine and Cosine functions (`sin`, `cos`).
*   **Visualization**: Mapping physical space to screen pixels.

### 4. Hardware Required
*   **Raspberry Pi Pico**
*   **Servo Motor**
*   **OLED Display (I2C)**

### 5. Wiring / Interfaces
| Component | Pico Pin | Notes |
| :--- | :--- | :--- |
| **Servo** | GP0 | PWM |
| **OLED SDA** | GP4 | I2C0 |

### 6. Blocks Used

*   From **Smart Display**, drag **`draw_line`**

### 7. Variables
*   **theta, rads, tip_x, tip_y**

### 8. Step-by-Step Guide
1.  **Parameters**:
    *   Define `Arm_Length = 40` (pixels).
    *   Define `Center_X = 64` (Screen width/2).
    *   Define `Center_Y = 64` (Screen bottom).
2.  **Kinematics Loop**:
    *   For `angle` from 0 to 180:
        *   Convert degrees to radians: `rads = angle * (Pi / 180)`.
        *   Calculate X: `tip_x = Center_X + Arm_Length * cos(rads)`.
        *   Calculate Y: `tip_y = Center_Y - Arm_Length * sin(rads)` (Note: Y is inverted on screens, 0 is top).
3.  **Render**:
    *   Clear Screen.
    *   Draw Line from `(Center_X, Center_Y)` to `(tip_x, tip_y)`.

    *   Update Screen.

### 9. Execution Flow
1.  **Start**: Arm at 0 degrees (Right). Screen shows line to right.
2.  **Move**: Arm arcs up to 90. Screen line arcs up.
3.  **End**: Arm at 180 (Left). Screen line to left.

### 10. Generated Code
``python
import machine
import utime
import math
from ssd1306 import SSD1306_I2C

# Setup
i2c = machine.I2C(0, sda=machine.Pin(4), scl=machine.Pin(5))
oled = SSD1306_I2C(128, 64, i2c)
servo = machine.PWM(machine.Pin(0))
servo.freq(50)

L = 40 # Arm length in pixels
CX = 64 # Pivot X
CY = 60 # Pivot Y (near bottom)

def set_angle(angle):
    duty = int(1000 + (angle/180) * 8000)
    servo.duty_u16(duty)

print("Visual Kinematics running...")

while True:
    for ang in range(0, 181, 5):
        # 1. Math
        # Servo 0 is usually left or right depending on mount. 
        # Let's assume 0 = Right (0 rad), 90 = Up (PI/2), 180 = Left (PI) for standard unit circle math.
        # But standard servo is often -90 to +90. Let's map 0-180 to PI to 0 for screen logic.
        
        rad = math.radians(ang)
        
        # Calculate Tip Position
        # Cos(0) = 1 (Right), Cos(180) = -1 (Left)
        # Sin(0) = 0, Sin(90) = 1 (Up)
        
        # Screen Corrdinates: X grows right, Y grows DOWN
        tip_x = CX + (L * math.cos(math.radians(180-ang))) # Invert X for visual matching if needed
        tip_y = CY - (L * math.sin(math.radians(180-ang))) # Minus because Y up is lower pixel value
        
        # 2. Draw
        oled.fill(0)
        oled.line(CX, CY, int(tip_x), int(tip_y), 1)
        oled.text(f"{ang} deg", 0, 0)
        oled.show()
        
        # 3. Move Physical
        set_angle(ang)
        utime.sleep(0.05)
        
    utime.sleep(1)
``

### 11. Common Mistakes
*   **Coordinate Confusion**: Screen Y=0 is top. Physics Y=0 is usually bottom/ground. Remember to subtract from Screen Height.
*   **Aspect Ratio**: Pixels might not be square, making the circle look oval.

## 1. Project 1103: Advanced Servo Kinematics Threshold Logic

### 2. Learning Objective
"Mechanical Stop Detection". Use a modified servo (with potentiometer feedback) to detect physical blockages. If the commanded position differs from the actual position (feedback) by a threshold, treat it as a collision and cut power.

### 3. Concepts Introduced
*   **Closed Loop Control**: Verifying output matches input.
*   **Stall/Collision Detection**: Identifying mechanical limits.
*   **Hysteresis**: Allowing small acceptable error.

### 4. Hardware Required
*   **Raspberry Pi Pico**
*   **Servo** (with 4th wire feedback mod)
*   **Potentiometer** (to simulate feedback/external force if no mod used)

### 5. Wiring / Interfaces
| Component | Pico Pin | Notes |
| :--- | :--- | :--- |
| **Servo Signal** | GP0 | PWM |
| **Feedback Wire** | GP26 | ADC0 (Voltage varies with angle) |

### 6. Blocks Used
*   From **Math**, drag **`abs`**
*   From **Logic**, drag **`if_compare`**

### 7. Variables
*   **cmd_angle, real_angle, error**

### 8. Step-by-Step Guide
1.  **Calibration**:
    *   Measure Feedback Voltage at 0 deg and 180 deg.
    *   Create a mapping function `volts_to_angle(v)`.
2.  **Move Routine**:
    *   Set Servo to Target Angle `T`.
    *   Wait small time (e.g., 200ms) for transit.
    *   Read Actual Angle `A` from feedback.
    *   Calculate `Error = abs(T - A)`.
3.  **Safety Logic**:
    *   If `Error > 15` (degrees):
        *   **Stall Detected**.
        *   Emergency Stop (Detach servo).
        *   Alert User.

### 9. Execution Flow
1.  **Move**: Servo moves to 90. Feedback reads 90. Error 0.
2.  **Block**: User holds servo arm at 45. Command is 90.
3.  **Detect**: Error = 45. "Collision!". Power Cut.

### 10. Generated Code
``python
import machine
import utime

servo = machine.PWM(machine.Pin(0)); servo.freq(50)
feedback = machine.ADC(26)

def SetAngle(a):
    d = int(1000 + (a/180)*8000)
    servo.duty_u16(d)

def GetActual():
    # Calibration assumed: 0.5V(10000) = 0deg, 2.5V(50000) = 180deg
    raw = feedback.read_u16()
    # Map raw to angle
    # angle = (raw - min) * (180 / (max - min))
    angle = (raw - 10000) * (180 / 40000) 
    return max(0, min(180, angle))

print("Smart Servo Ready")

targets = [0, 45, 90, 135, 180]

while True:
    for t in targets:
        print(f"Moving to {t}...")
        SetAngle(t)
        
        # Give time to move
        for i in range(10):
            utime.sleep(0.05)
            # Check mid-flight? Or wait till end?
            
        real = GetActual()
        error = abs(t - real)
        print(f"Cmd: {t}, Real: {real:.1f}, Err: {error:.1f}")
        
        if error > 15:
            print("CRITICAL: STALL DETECTED!")
            servo.duty_u16(0) # Cut power
            while True: # Halt
                utime.sleep(0.1) 
        
        utime.sleep(1)
``

### 11. Common Mistakes
*   **Voltage Divider**: Ideally feedback voltage shouldn't exceed 3.3V. If Modding a 5V servo, use a voltage divider on the feedback wire!

### 12. Try This Next
*   **Complaint Compliance**: If blocked, update Target to match Actual (Yielding/Compliance).

## 1. Project 1105: Automated Advanced Servo Kinematics Controller

### 2. Learning Objective
"Inverse Kinematics 2D". Control a 2-segment Robot Arm (Shoulder, Elbow) to reach a specific X-Y coordinate. The code calculates the required angles automatically.

### 3. Concepts Introduced
*   **Inverse Kinematics (IK)**: Coordinates -> Angles.
*   **Law of Cosines**: Solving triangles with SSS (Side-Side-Side).
*   **Constraints**: Understanding workspace limits.

### 4. Hardware Required
*   **Raspberry Pi Pico**
*   **2 Servos** (Shoulder, Elbow)
*   **Linkages** (e.g., popsicle sticks, 50mm each)

### 5. Wiring / Interfaces
| Component | Pico Pin | Notes |
| :--- | :--- | :--- |
| **Shoulder Servo** | GP0 | |
| **Elbow Servo** | GP1 | |

### 6. Blocks Used
*   From **Math**, drag **`acos`**, **`atan`**, **`sqrt`**

### 7. Variables
*   **L1, L2, target_x, target_y**

### 8. Step-by-Step Guide
1.  **Geometry**:
    *   Length 1 (`L1`) = 50mm. Length 2 (`L2`) = 50mm.
    *   Target `(x, y)`.
2.  **Math**:
    *   Distance to target `r = sqrt(x^2 + y^2)`.
    *   If `r > L1 + L2`: Target Unreachable! Clip to max reach.
    *   Apply **Law of Cosines** to find `Elbow_Angle` (q2).
    *   Calculate `Shoulder_Angle` (q1) using `atan(y/x)` +/- geometric offsets.
3.  **Actuate**:
    *   Convert `q1`, `q2` (radians) to degrees.
    *   Map to Servo PWM.
    *   Move Servos.

### 9. Execution Flow
1.  **Command**: `GoTo(50, 50)`.
2.  **Calc**: Solves angles.
3.  **Action**: Arm extends to exactly 50mm right, 50mm up.

### 10. Generated Code
``python
import machine
import utime
import math

shoulder = machine.PWM(machine.Pin(0)); shoulder.freq(50)
elbow = machine.PWM(machine.Pin(1)); elbow.freq(50)

L1 = 50.0 # mm
L2 = 50.0 # mm

def set_s(s, angle):
    # Safe map
    angle = max(0, min(180, angle))
    d = int(1000 + (angle/180)*8000)
    s.duty_u16(d)

def inverse_kinematics(x, y):
    # 1. Distance
    r = math.sqrt(x*x + y*y)
    
    # 2. Reach Check
    if r > (L1 + L2):
        print("Unreachable")
        r = L1 + L2 - 1 # Clamp
        
    # 3. Law of Cosines for Elbow (q2)
    # c^2 = a^2 + b^2 - 2ab cos(C)
    # r^2 = L1^2 + L2^2 - 2*L1*L2 * cos(180-q2)
    # Let's simplify:
    # Cos(angle_at_elbow) = (L1^2 + L2^2 - r^2) / (2*L1*L2)
    numerator = (L1*L1 + L2*L2 - r*r)
    denominator = (2 * L1 * L2)
    cos_elbow_inner = numerator / denominator
    
    # Clamp domain for acos
    cos_elbow_inner = max(-1, min(1, cos_elbow_inner))
    elbow_inner_angle = math.acos(cos_elbow_inner)
    
    # q2 (Elbow relative to L1)
    q2 = 180 - math.degrees(elbow_inner_angle)
    
    # 4. Shoulder (q1)
    # Base angle to target
    a1 = math.atan2(y, x)
    # Offset angle inside triangle
    # Cos(a2) = (L1^2 + r^2 - L2^2) / (2*L1*r)
    num2 = (L1*L1 + r*r - L2*L2)
    den2 = (2 * L1 * r)
    a2 = math.acos(max(-1, min(1, num2/den2)))
    
    q1 = math.degrees(a1 + a2)
    
    return q1, q2

# Test Triangle path
points = [(50,0), (80,20), (50,50)]

while True:
    for px, py in points:
        print(f"GoTo: {px},{py}")
        q1, q2 = inverse_kinematics(px, py)
        print(f"Angles: {q1:.1f}, {q2:.1f}")
        set_s(shoulder, q1)
        set_s(elbow, q2)
        utime.sleep(1)
``

### 11. Common Mistakes
*   **Coordinate System**: Ensure your math (0 degrees = X axis) matches your servo mount (0 degrees = Horizontal). Offsets often required.

### 12. Try This Next
*   **Trajectory**: Interpolate linear path between points (Draw a line, not just jump).

## 1. Project 1106: Advanced Servo Kinematics Safety Trigger

### 2. Learning Objective
"Speed Governor". Limit the maximum rotational velocity of a servo. Even if the command jumps from 0 to 180, the code interpolates intermediate steps to ensure the arm moves at a safe, controlled speed (`30 deg/sec`).

### 3. Concepts Introduced
*   **Motion Profiling**: Controlling velocity and acceleration.
*   **Slew Rate Limiting**: Capping change per unit time.
*   **Interpolation**: Generating intermediate points.

### 4. Hardware Required
*   **Raspberry Pi Pico**
*   **Servo**

### 5. Wiring / Interfaces
| Component | Pico Pin | Notes |
| :--- | :--- | :--- |
| **Servo** | GP0 | |

### 6. Blocks Used
*   From **Math**, drag **`min`, `max`**

### 7. Variables
*   **current_angle, target, max_step**

### 8. Step-by-Step Guide
1.  **Config**: `MAX_SPEED = 1` (degree per loop cycle).
2.  **Control Loop**:
    *   Read `Target`.
    *   Calculate `Diff = Target - Current`.
    *   **Clamp**: Ensure `Diff` is not larger than `MAX_SPEED`.
        *   `Step = max(-MAX_SPEED, min(MAX_SPEED, Diff))`.
    *   `Current = Current + Step`.
    *   Move Servo to `Current`.
    *   `Sleep` (e.g., 20ms).
3.  **Effect**: Large jumps become smooth ramps.

### 9. Execution Flow
1.  **Cmd**: Jump to 180.
2.  **Result**: Arm moves 1..2..3..4... steadily to 180.

### 10. Generated Code
``python
import machine
import utime

servo = machine.PWM(machine.Pin(0)); servo.freq(50)

current_pos = 90
target_pos = 90
MAX_STEP_PER_CYCLE = 2 # Degrees per 20ms = 100 deg/sec

def set_raw(a):
    d = int(1000 + (a/180)*8000)
    servo.duty_u16(d)

print("Govener Active")

while True:
    # 1. User Input (Simulated random moves)
    if utime.ticks_ms() % 2000 == 0:
        import random
        target_pos = random.randint(0, 180)
        print(f"New Target: {target_pos}")
        
    # 2. Physics Update
    diff = target_pos - current_pos
    
    # 3. Slew Rate Limit
    if diff > MAX_STEP_PER_CYCLE:
        step = MAX_STEP_PER_CYCLE
    elif diff < -MAX_STEP_PER_CYCLE:
        step = -MAX_STEP_PER_CYCLE
    else:
        step = diff # Close enough
        
    current_pos += step
    
    # 4. Actuate
    set_raw(current_pos)
    
    utime.sleep(0.02) # 50Hz Loop
``

### 11. Common Mistakes
*   **Blocking Sleep**: Don't use `sleep(2)` inside the movement loop. It must be non-blocking ticks.

### 12. Try This Next
*   **Ease-In-Out**: Vary `MAX_STEP` based on distance (accel/decel).

## 1. Project 1108: Smart Advanced Servo Kinematics System

### 2. Learning Objective
"Sync Dance". Coordinate three separate Pico units (Master + 2 Slaves) to move servos in unison. Master sends a precise trigger signal, Slaves execute a pre-loaded motion sequence.

### 3. Concepts Introduced
*   **Multi-Agent Coordination**.
*   **Edge-Triggered Sync**.
*   **Distributed Control**.

### 4. Hardware Required
*   **3x Raspberry Pi Pico**
*   **3x Servos**
*   **Jumper Wires** (Ground + Signal)

### 5. Wiring / Interfaces
| Component | Pico Pin | Notes |
| :--- | :--- | :--- |
| **Sync Output (Master)** | GP16 | Connect to Slaves' GP16 |
| **Sync Input (Slave)** | GP16 | Connect to Master |
| **GND** | GND | Common Ground REQUIRED |
| **Servo** | GP0 | |

### 6. Blocks Used
*   From **Events**, drag **`on_interrupt` (IRQ)**

### 7. Variables
*   **sequence_active**

### 8. Step-by-Step Guide
1.  **Slave Code**:
    *   Setup GP16 as Input with Pull-Down.
    *   Attach IRQ (Rising Edge) to function `start_routine`.
    *   Routine: Loop 0 to 180 and back.
2.  **Master Code**:
    *   Setup GP16 as Output.

### 7. Variables

### 8. Step-by-Step Guide
1.  **PID Algo**:
    *   `Error = Target - Actual`.
    *   `Integral = Integral + Error`.
    *   `Derivative = Error - Last_Error`.
    *   `Output = (Kp * Error) + (Ki * Integral) + (Kd * Derivative)`.
2.  **Simulation Loop**:
    *   Use `Output` to drive servo velocity (simulated).
    *   If using real servo, map `Output` to position relative to current.
3.  **Tuning**:

### 10. Generated Code
``python

import utime

# since standard servos hide the PID loop.
# We will drive Position based on our own PID Loop calculation.

kp_pot = machine.ADC(26)
servo = machine.PWM(machine.Pin(0)); servo.freq(50)

target = 90
current_sim = 0.0 # Simulated physics position
velocity = 0.0

integral = 0
last_error = 0

print("PID Tuning Mode")

while True:
    # 1. Read Gain
    Kp = (kp_pot.read_u16() / 65535) * 1.0 # 0.0 to 1.0
    
    # 2. Physics Model (Simple Inertia)
    error = target - current_sim
    integral += error * 0.1
    derivative = (error - last_error) / 0.1
    
    # PID Output
    force = (Kp * error) + (0.01 * integral) + (0.05 * derivative)
    
    # Apply Force to Mass
    velocity += force
    velocity *= 0.9 # Friction/Damping
    current_sim += velocity
    
    last_error = error
    
    # 3. Visualize on Real Servo
    # Map simulated float pos to integer duty
    safe_pos = max(0, min(180, int(current_sim)))
    d = int(1000 + (safe_pos/180)*8000)
    servo.duty_u16(d)
    
    # Toggle Target
    if utime.ticks_ms() % 2000 < 50:
        target = 180 if target == 0 else 0
        integral = 0 # Reset I on step
        
    utime.sleep(0.02)
    # print(f"Pos: {current_sim:.1f}, Kp: {Kp:.2f}")
``

import utime

state = False # False=White, True=Black
last_transition = 0

print("Swipe Barcode Now...")

# Capture Phase
start_capture = utime.ticks_ms()
while utime.ticks_diff(utime.ticks_ms(), start_capture) < 5000:
    val = ldr.read_u16()
    is_black = (val < THRESHOLD)
    
    if is_black != state:
        now = utime.ticks_ms()
        if state == True: 
            # End of a Black bar (Black -> White)
            duration = utime.ticks_diff(now, last_transition)
            # Filter noise clips < 20ms
            if duration > 20:
                pulses.append(duration)
                print(f"Pulse: {duration}ms")
        
        last_transition = now
        state = is_black
        
    utime.sleep_us(100) # Fast sampling

# Decode Phase
if len(pulses) > 0:
    avg = sum(pulses) / len(pulses)
    code = ""
    for p in pulses:
        if p > avg: code += "1"
        else: code += "0"
        
    print(f"Decoded: {code}")
else:
    print("No bars detected.")
``

### 8. Step-by-Step Guide

``python
import machine
import utime
import rp2

# Simplified PIO for Pulse Width Measurement
@rp2.asm_pio(set_init=rp2.PIO.IN_HIGH, autopush=True, push_thresh=32)
def dht_capture():
    # 1 loop cycle = 1 us (freq=1000000)
    # This is a simplified educational example.
    # Real implementations typically use C-modules because blocking python is tricky.
    
    # Wait for pin to go low (Start of response)
    wait(0, pin, 0)
    # Wait for pin to go high
    wait(1, pin, 0)
    
    label("loop")
    # Wait for low (Start of bit)
    wait(0, pin, 0)
    # Wait for high (Start of data)
    wait(1, pin, 0)
    
    # Count High Duration
    mov(x, invert(null)) # Set X to 0xFFFFFFFF
    label("count_high")
    jmp(pin, "continue_count")
    jmp("bit_end")
    label("continue_count")
    jmp(x_dec, "count_high")
    
    label("bit_end")
    # Push X (Counter) to FIFO
    in_(x, 32)
    jmp("loop")

# Note: Writing robust PIO DHT11 drivers is complex.
# For standard use, use the built-in `dht` module:
import dht
sensor = dht.DHT11(machine.Pin(16))

while True:
    try:
        sensor.measure()
        t = sensor.temperature()
        h = sensor.humidity()
        print(f"Temp: {t}C, Hum: {h}%")
    except OSError as e:
        print("Sensor Error")
        
    utime.sleep(2)
``

## 1. Project 1125: Automated Advanced Temp/Humidity (DHT) Controller

### 2. Learning Objective
"Incubator Controller". Implement a PID (Proportional-Integral-Derivative) control loop to maintain a precise temperature (e.g., 37.5°C) by modulating a heater. Unlike On/Off thermostats, PID provides smooth power control to prevent overshoot.

### 3. Concepts Introduced
*   **PID Control**: Feedback mechanism (P=Current, I=Past, D=Future).
*   **PWM Heating**: Controlling power via duty cycle.
*   **Thermal Inertia**: Lag between heating and sensing.

### 4. Hardware Required
*   **Raspberry Pi Pico**
*   **DHT11 Sensor**
*   **Heater Module** (e.g., Ceramic Resistor + MOSFET Driver)
*   **External Power Supply** (for Heater)

### 5. Wiring / Interfaces
| Component | Pico Pin | Notes |
| :--- | :--- | :--- |
| **DHT11** | GP16 | |
| **Heater MOSFET** | GP15 | PWM Output |
| **External Power** | - | Connected to Heater |

### 6. Blocks Used
*   From **Math**, drag **`calc`**
*   From **Motion & Motors**, drag **`set_duty`**

### 7. Variables
*   **target_temp, current_temp**
*   **kp, ki, kd**
*   **error, integral, last_error**

### 8. Step-by-Step Guide
1.  **Read Temp**: Get `current_temp` from DHT11.
2.  **Calculate Error**: `error = target_temp - current_temp`.
3.  **PID Terms**:
    *   `P = kp * error`
    *   `Integral = Integral + error`. `I = ki * Integral`.
    *   `Derivative = error - last_error`. `D = kd * Derivative`.
4.  **Output**:
    *   `Power = P + I + D`.
    *   Clamp `Power` to 0-65535 (PWM range).
5.  **Actuate**: Write `Power` to Heater PWM.
6.  **Update**: `last_error = error`. Loop.

### 9. Execution Flow
1.  **Start**: Temp 20C. Target 37C. Error 17. Power 100%.
2.  **Approaching**: Temp 36C. Error 1. Power reduces.
3.  **Stable**: Temp 37C. Error 0. Integral maintains small heat to match loss.

### 10. Generated Code
``python
import machine
import utime
import dht

sensor = dht.DHT11(machine.Pin(16))
heater = machine.PWM(machine.Pin(15))
heater.freq(10) # Low freq for heaters usually fine

TARGET = 37.5
Kp = 5000 # Prop Gain
Ki = 100  # Integral Gain
Kd = 10000 # Derivative Gain

integral = 0
last_error = 0

print("Incubator Active...")

while True:
    try:
        sensor.measure()
        t = sensor.temperature()
    except:
        t = last_error # Safe fallback
        
    error = TARGET - t
    
    # Integral Windup Guard
    integral += error
    if integral > 1000: integral = 1000
    if integral < -1000: integral = -1000
    
    derivative = error - last_error
    
    # PID Calc
    output = (Kp * error) + (Ki * integral) + (Kd * derivative)
    
    # Clamp to PWM
    pwm_val = int(max(0, min(65535, output)))
    
    heater.duty_u16(pwm_val)
    
    print(f"T: {t}C | Out: {pwm_val} | E: {error}")
    
    last_error = error
    utime.sleep(2) # DHT11 is slow
``

### 11. Common Mistakes
*   **Safety**: Heaters get HOT. Ensure MOSFET is rated for current. Never leave unattended.
*   **Tuning**: If it oscillates (Hot/Cold/Hot), reduce Kp. If it never reaches target, increase Ki.

### 8. Step-by-Step Guide

2.  **Read Internal**:
    *   ADC(4).
    *   `Volts = ADC * 3.3 / 65535`.
    *   `internal_t = 27 - (Volts - 0.706) / 0.001721`.
3.  **Cross-Check**:
    *   `diff = abs(internal_t - external_t)`.
4.  **Verdict**:
    *   If `diff > 10`: "Sensor Mismatch!".
    *   Else: "Sensors Agree".

### 9. Execution Flow

``python

import utime
import dht

adc_internal = machine.ADC(4)
led = machine.Pin(15, machine.Pin.OUT)

CONV = 3.3 / 65535

def get_cpu_temp():
    raw = adc_internal.read_u16()
    volts = raw * CONV
    temp = 27 - (volts - 0.706) / 0.001721
    return temp

while True:
    try:
        dht_sens.measure()
        ext = dht_sens.temperature()
    except:
        ext = -999
        
    cpu = get_cpu_temp()
    
    diff = abs(cpu - ext)
    
    print(f"CPU: {cpu:.1f}C | Room: {ext}C | Diff: {diff:.1f}")
    
    # CPU is usually 5-10C hotter than room
    # So a massive diff implies something is wrong
    if diff > 15: 
        print("ALARM: Sensors Disagree")
        led.value(1)
    else:
        led.value(0)
        
    utime.sleep(2)
``

### 11. Common Mistakes

## 1. Project 1129: Advanced Temp/Humidity (DHT) Calibration Tool

### 2. Learning Objective
"Response Time (Tau)". Measure the **Time Constant** of the sensor. How long does it take for the reading to change from `T_initial` to `63%` of the way to `T_final`? This characterizes thermal inertia.

### 3. Concepts Introduced
*   **Time Constant (Tau)**: Standard metric for sensor speed.
*   **Step Response**: Analyzing reaction to sudden change.

### 4. Hardware Required
*   **Raspberry Pi Pico**
*   **DHT11 Sensor**
*   **Heat Source** (Warm hands or Hair dryer - Gentle!)

### 5. Wiring / Interfaces
| Component | Pico Pin | Notes |
| :--- | :--- | :--- |
| **DHT11** | GP16 | |

### 6. Blocks Used
*   from **Smart IO**, drag **`ticks_ms`**, **`ticks_diff`**

### 7. Variables
*   **t1, t2, start_time, lapsed**

### 8. Step-by-Step Guide
1.  **Baseline**: Measure Room Temp for 5 seconds. Average it (`T_cold`).
2.  **Trigger**: User touches sensor.
3.  **Detect**: When Temp > `T_cold + 2C`, Start Timer.
4.  **Wait**: Wait until Temp stabilizes (no change for 10s) -> `T_hot`.
5.  **Calculate**: Find time when Temp passed `T_cold + 0.63 * (T_hot - T_cold)`.
6.  **Output**: "Tau = [Time] seconds".

### 9. Execution Flow
1.  **Start**: "Ready. Apply Heat."
2.  **Heat**: Temp rises... 22.. 25.. 30.. 32(Stable).
3.  **Calc**: 63% mark was at 28.3C. Time to reach 28.3C was 15s.
4.  **Result**: "Tau = 15.0s".

### 10. Generated Code
``python

import dht
import utime

print("Stabilizing...")
utime.sleep(2)
sens.measure()
t_cold = sens.temperature()

print(f"Baseline: {t_cold}C. Apply Heat NOW!")

data = []
start_t = utime.ticks_ms()

# 1. Capture Data until Stable
last_t = t_cold
stable_count = 0

while True:
    try:
        sens.measure()
        t = sens.temperature()
        now = utime.ticks_diff(utime.ticks_ms(), start_t) / 1000.0
        data.append((now, t))
        
        print(f"T: {t}C @ {now:.1f}s")
        
        if t == last_t and t > t_cold + 5:
            stable_count += 1
        else:
            stable_count = 0
            
        if stable_count > 5: # Stable for 10s (assuming 2s interval)
            break
            
        last_t = t
        utime.sleep(2)
    except:
        pass

# 2. Analyze
t_hot = data[-1][1]
target = t_cold + 0.632 * (t_hot - t_cold) # Tau point
print(f"Max: {t_hot}C. Target Tau: {target:.1f}C")

tau = 0
for timestamp, reading in data:
    if reading >= target:
        tau = timestamp
        break

print(f"Sensor Time Constant (Tau) = {tau} seconds")
``

## 1. Project 1130: Advanced Temp/Humidity (DHT) Prototype

### 2. Learning Objective
"VPD Calculator". Calculate **Vapor Pressure Deficit (VPD)**. This is a critical metric in Indoor Farming (Hydroponics) indicating the "drying power" of the air. It combines Temp and Humidity into a single value representing plant transpiration stress.

### 3. Concepts Introduced
*   **Psychrometrics**: Physics of moist air.
*   **SVP (Saturation Vapor Pressure)**.
*   **AVP (Actual Vapor Pressure)**.

### 4. Hardware Required
*   **Raspberry Pi Pico**
*   **DHT11 Sensor**
*   **OLED Display** (Optional, for dashboard)

### 5. Wiring / Interfaces
| Component | Pico Pin | Notes |
| :--- | :--- | :--- |
| **DHT11** | GP16 | |

### 6. Blocks Used
*   From **Math**, drag **`exp`**, **`arithmetic`**

### 7. Variables
*   **SVP, AVP, VPD**

### 8. Step-by-Step Guide
1.  **Formula (Tetens)**:
    *   `SVP = 0.6108 * exp((17.27 * T) / (T + 237.3))` (in kPa).
    *   `AVP = SVP * (RH / 100)`.
    *   `VPD = SVP - AVP`.
2.  **Ranges**:
    *   Low (<0.4 kPa): Mushroom/Clone.
    *   Mid (0.8-1.2 kPa): Vegetative.
    *   High (>1.6 kPa): Stressed.
3.  **Smart Display**: Show VPD and "Zone" (Veg/Bloom/Stress).

### 9. Execution Flow
1.  **Input**: 25C, 50% RH.
2.  **SVP**: 3.16 kPa.

4.  **VPD**: 1.58 kPa.
5.  **Output**: "High Transpiration".

### 10. Generated Code
``python

import dht
import utime
import math

sens = dht.DHT11(machine.Pin(16))

while True:
    try:
        sens.measure()
        t = sens.temperature()
        rh = sens.humidity()
        
        # 1. Calculate SVP (kPa)
        svp = 0.6108 * math.exp((17.27 * t) / (t + 237.3))
        
        # 2. Calculate AVP
        avp = svp * (rh / 100.0)
        
        # 3. VPD
        vpd = svp - avp
        
        status = "Good"
        if vpd < 0.4: status = "Too Humid (Mold Risk)"
        elif vpd < 0.8: status = "Low Transpiration"
        elif vpd > 1.6: status = "Stressed (Too Dry)"
        
        print(f"T:{t}C H:{rh}% | VPD: {vpd:.2f} kPa | {status}")
        
    except:
        pass
        
    utime.sleep(2)
``

*   **Pressure Unit**: Result is kPa (Kilopascals). Some charts use hPa or psi.

    *   `Now = ticks_us()`.
    *   `Diff = Now - last_time`.

### 10. Generated Code
``python
import machine
import utime

ir_pin = machine.Pin(16, machine.Pin.IN, machine.Pin.PULL_UP)

data = []
last_time = 0
collecting = False

def ir_handler(pin):
    global last_time, collecting
    
    now = utime.ticks_us()
    
    if not collecting:
        # First edge
        collecting = True
        data.clear()
    else:
        diff = now - last_time
        data.append(diff)
        
    last_time = now

# Setup IRQ
ir_pin.irq(trigger=machine.Pin.IRQ_FALLING | machine.Pin.IRQ_RISING, handler=ir_handler)

print("Capture Mode Ready. Press Remote Button.")

while True:
    if collecting:
        # Check for silence (End of transmission)
        if utime.ticks_diff(utime.ticks_us(), last_time) > 200000: # 200ms silence

"Hash Matcher". Instead of storing massive lists of raw timings (which eat RAM), calculate a unique "Fingerprint" (Hash) for each button. This allows you to recognize buttons ("Volume Up") without needing to decode the complex NEC/Sony/RC5 protocol.

### 8. Step-by-Step Guide
1.  **Capture**: Get the raw list of timings (from P1131).
2.  **Quantize**: Round every timing to the nearest 100us. (Crucial! 560us and 540us must both become 600us or 500us to match).
3.  **Hash Algorithm**:
    *   Simple: Sum of all timings? (Weak, different buttons might have same length).
    *   Better: `Hash = (Hash * 33) + Timing`. (DJB2 variant).
4.  **Match**:
    *   Record Hash for "Power" -> `123456`.
    *   When new signal comes, if Hash == `123456`, print "Power Pressed".

### 9. Execution Flow
1.  **Train**: User presses 'A'. Pico says "Hash: 44921".
2.  **Code**: User updates code: `if hash == 44921: ACTION`.
3.  **Run**: Press 'A'. Pico says "Action Triggered!".

``python

import math

def get_ir_packet():
    # Blocking call to capture one packet (simplified)
    # real code would use IRQ
    while ir.value() == 1: pass # Wait for low
    
    timings = []
    last = utime.ticks_us()
    
    while True:
        val = ir.value()
        start_wait = utime.ticks_us()
        # Wait for state change
        while ir.value() == val:
            if utime.ticks_diff(utime.ticks_us(), start_wait) > 20000:
                # Timeout / End
                return timings
        now = utime.ticks_us()
        timings.append(now - last)
        last = now

def calculate_hash(timings):
    h = 5381
    for t in timings:
        # Quantize to nearest 50us to handle jitter
        q = int(round(t / 50.0) * 50)
        h = ((h << 5) + h) + q # h * 33 + q
    return h & 0xFFFFFFFF # Keep 32-bit

print("Ready. Press matching button...")

        sig = calculate_hash(packet)

        if sig == TARGET_HASH:
            print(">> TARGET MATCHED!")
            
    utime.sleep(0.2)

## 1. Project 1141: Advanced Keypad Security Sensor Setup

### 2. Learning Objective
"IO Expander Keypad". Connect a 4x4 Keypad (8 pins) to a Pico using *only* 2 wires (I2C) via a PCF8574 IO Expander. This is critical when you run out of GPIO pins on complex projects.

### 3. Concepts Introduced
*   **Port Expansion**: Multiplying GPIO.
*   **I2C Protocol**: Addressing and Data Frames.
*   **Scanning Algorithm**: Walking 1s across rows through a remote chip.

### 4. Hardware Required
*   **Raspberry Pi Pico**
*   **PCF8574 Module** (I2C Backpack)
*   **4x4 Matrix Keypad**

### 5. Wiring / Interfaces
| Component | Pico Pin | Notes |
| :--- | :--- | :--- |
| **PCF SDA** | GP4 | |
| **PCF SCL** | GP5 | |
| **Keypad** | PCF P0-P7 | P0-P3=Rows, P4-P7=Cols |

### 6. Blocks Used
*   From **Communication**, drag **`i2c_write`**, **`i2c_read`**

### 7. Variables
*   **row_mask**, **col_mask**

### 8. Step-by-Step Guide
1.  **Library**: We define a simple `KeypadI2C` class because no standard driver exists in ROM.
2.  **Scan Logic**:
    *   Write `0xFE` (11111110) -> Pull Row 0 Low.
    *   Read High nibble (Cols). If a Col is Low, button is pressed.
    *   Repeat for Row 1 (`0xFD`), Row 2 (`0xFB`), Row 3 (`0xF7`).
3.  **Decode**: Convert `(Row, Col)` index to Character (`1`, `2`, `A`...).

### 9. Execution Flow
1.  **Idle**: PCF outputs High on all Rows.
2.  **Press**: Button connects Row to Col.
3.  **Scan**: Controller cycles rows, finds the connection. Returns '5'.

### 10. Generated Code
``python
import machine
import utime

# I2C Setup
i2c = machine.I2C(0, sda=machine.Pin(4), scl=machine.Pin(5), freq=100000)
PCF_ADDR = 0x27 # Check your module! usually 0x27 or 0x3F

KEYS = [
    ['1', '2', '3', 'A'],
    ['4', '5', '6', 'B'],
    ['7', '8', '9', 'C'],
    ['*', '0', '#', 'D']
]

def scan_keypad():
    # 1. Drive Rows Low one by one
    for r in range(4):
        # Create mask: Row r is LOW (0), others HIGH (1)
        # Low nibble = Row, High nibble = 1 (Input/Pullup tentative)
        # Actually PCF8574 has weak pullups. Writing 1 = Input/High. Writing 0 = Low sink.
        
        # We want to Write 0 to ONE Row, and 1 to all Cols (to listen).
        # P0-P3 = Rows. P4-P7 = Cols.
        # To sink Row 0: 1111 1110 -> 0xFE
        row_mask = ~(1 << r) & 0x0F # Logic for Rows
        
        # Write: Cols High (Input), Selected Row Low
        payload = 0xF0 | row_mask
        
        try:
            i2c.writeto(PCF_ADDR, bytes([payload]))
            response = i2c.readfrom(PCF_ADDR, 1)[0]
        except:
            return None # I2C Error
            
        # Parse Cols (High Nibble)
        # If no key pressed, Cols are ALL 1 (due to pullup) -> 0xF0
        col_nibble = (response >> 4) & 0x0F
        
        if col_nibble != 0x0F: # Something pulled low
            for c in range(4):
                if not ((col_nibble >> c) & 1):
                    return KEYS[r][c]
                    
    return None

print("Keypad I2C Ready...")

while True:
    key = scan_keypad()
    if key:
        print(f"Key: {key}")
        utime.sleep(0.3) # Debounce
``

### 11. Common Mistakes
*   **Addressing**: If `0x27` doesn't work, try `0x3F`. Run an I2C scan code to find it.
*   **Ghosting**: Pressing 3 keys at once can register a false 4th key without Diodes. Standard keypads don't have diodes.

*   **Interrupt**: Connect the PCF8574 `INT` pin to a Pico GPIO. Only scan when `INT` goes Low (IRQ driven), saving massive CPU time vs polling.

2.  **Formula**: `(Val - Min) * (OutMax - OutMin) / (InMax - InMin) + OutMin`.

adc_y = machine.ADC(27)

    return int((x - in_min) * (out_max - out_min) / (in_max - in_min) + out_min)

while True:
    raw_x = adc_x.read_u16()
