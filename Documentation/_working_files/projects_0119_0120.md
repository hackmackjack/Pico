
## Project 0119: Automated Animation

### 1. Learning Objective
Create scrolling text animations. Learn string manipulation and horizontal text shifting.

### 2. Concepts Introduced
*   **Text Scrolling**: Moving text horizontally across screen
*   **Position Offset**: Using X-coordinate to simulate movement
*   **Marquee Effect**: Continuous right-to-left text flow

### 3. Hardware Required
*   Raspberry Pi Pico
*   SSD1306 OLED Display
*   Breadboard and jumper wires

### 4. Wiring / Interfaces
*(Same as Project 0111)*

### 5. Blocks Used
*   **from Loops, drag `pico_forever`** (forever do)
*   **from Smart Display, drag `pico_oled_init`** (initialize OLED)
*   **from Smart Display, drag `pico_oled_text`** (display text)
*   **from Smart Display, drag `pico_oled_clear`** (clear screen)
*   **from Smart Display, drag `pico_oled_show`** (update display)
*   **from Variables, drag `variables_set`** (set variable to)
*   **from Math, drag `math_arithmetic`** (arithmetic operations)
*   **from Time, drag `pico_wait`** (wait)

### 6. Variables
*   **text_x**: Horizontal position of text (starts at 128, moves left)
*   **message**: The string to scroll

### 7. Step-by-Step Guide

**A. Initialization Phase**
1.  **Initialize OLED**: Standard setup.

2.  **Initialize Text Variables**:
    *   From **Variables**, drag `variables_set`.
    *   **Set** `message` = "Hello World, Welcome to Pico!"
    *   **Set** `text_x` = 128 (starting position off right edge).

**B. Main Loop Phase**
3.  **Create Forever Loop**:
    *   From **Loops**, drag `pico_forever` block.

4.  **Clear Screen**:
    *   From **Smart Display**, drag `pico_oled_clear`.

5.  **Draw Text at Current Position**:
    *   From **Smart Display**, drag `pico_oled_text`.
    *   **Display** `message` at position (`text_x`, 28).

6.  **Update Display**:
    *   From **Smart Display**, drag `pico_oled_show`.

7.  **Move Text Left**:
    *   From **Math**, calculate:
    *   `text_x` = `text_x` - 2 (move 2 pixels left per frame).

8.  **Reset When Off-Screen**:
    *   From **Logic**, drag `controls_if`.
    *   **If** `text_x` < -240:
        *   **Then**: `text_x` = 128 (reset to right edge)

9.  **Frame Delay**:
    *   From **Time**, drag `pico_wait` -> 0.05 seconds.

### 8. Execution Flow
1.  **Start**: Initialize display, set text starting position off right edge.
2.  **Loop**: Clear screen, draw text at X, update, move left, reset if needed, wait.
3.  **Result**: Continuous left-scrolling marquee text.

### 9. Generated Code
```python
from machine import Pin, I2C
from ssd1306 import SSD1306_I2C
import time

# Initialize OLED
i2c = I2C(0, sda=Pin(0), scl=Pin(1), freq=400000)
oled = SSD1306_I2C(128, 64, i2c)

# Initialize text
message = "Hello World, Welcome to Pico!"
text_x = 128
text_width = len(message) * 8

# Main loop
while True:
    oled.fill(0)
    oled.text(message, text_x, 28)
    oled.show()
    text_x -= 2
    if text_x < -text_width:
        text_x = 128
    time.sleep(0.05)
```

### 10. Common Mistakes
*   **Wrong Reset Point**: Resetting too early causes text to jump while still visible.
*   **Speed Too Fast**: Moving > 3 pixels/frame makes text hard to read.
*   **No Clear**: Not clearing screen causes overlapping text trail.

### 11. Try This Next
*   **Vertical Scroll**: Make text scroll up instead of sideways.
*   **Two-Line Scroll**: Display two messages scrolling at different speeds.
*   **Sensor-Controlled Speed**: Use potentiometer to adjust scroll speed.

## Project 0120: Mastering Animation

### 1. Learning Objective
Implement multi-frame sprite animation with movement. Learn bitmap graphics and frame cycling.

### 2. Concepts Introduced
*   **Sprite Sheet**: Multiple frames of animation stored as bitmaps
*   **Frame Cycling**: Alternating between frames to create motion illusion
*   **Bitmap Data**: Array of bytes representing pixel patterns

### 3. Hardware Required
*   Raspberry Pi Pico
*   SSD1306 OLED Display
*   Breadboard and jumper wires

### 4. Wiring / Interfaces
*(Same as Project 0111)*

### 5. Blocks Used
*   **from Loops, drag `pico_forever`** (forever do)
*   **from Smart Display, drag `pico_oled_init`** (initialize OLED)
*   **from Smart Display, drag `pico_oled_bitmap`** (draw bitmap)
*   **from Smart Display, drag `pico_oled_clear`** (clear screen)
*   **from Smart Display, drag `pico_oled_show`** (update display)
*   **from Variables, drag `variables_set`** (set variable to)
*   **from Logic, drag `controls_if`** (if / else)
*   **from Math, drag `math_arithmetic`** (modulo operation)
*   **from Lists, drag lists** (to store bitmap frames)
*   **from Time, drag `pico_wait`** (wait)

### 6. Variables
*   **pac_x**: Horizontal position of Pac-Man
*   **frame**: Current animation frame (0 or 1)
*   **frame_counter**: Counts frames for animation timing
*   **pac_open**: Bitmap for open mouth
*   **pac_closed**: Bitmap for closed mouth

### 7. Step-by-Step Guide

**A. Initialization Phase**
1.  **Initialize OLED**: Standard setup.

2.  **Define Bitmap Arrays**:
    *   Create `pac_open` bitmap (8x8 pixels) representing Pac-Man with open mouth
    *   Create `pac_closed` bitmap (8x8 pixels) representing Pac-Man with closed mouth

3.  **Initialize Variables**:
    *   From **Variables**, drag `variables_set`.
    *   **Set** `pac_x` = 0 (starting at left edge).
    *   **Set** `frame` = 0.
    *   **Set** `frame_counter` = 0.

**B. Main Loop Phase**
4.  **Create Forever Loop**:
    *   From **Loops**, drag `pico_forever` block.

5.  **Clear Screen**:
    *   From **Smart Display**, drag `pico_oled_clear`.

6.  **Animate Frame**:
    *   From **Math**, calculate: `frame_counter` = `frame_counter` + 1
    *   **If** `frame_counter` modulo 10 == 0:
        *   **Then**: `frame` = 1 - `frame` (toggle between 0 and 1)

7.  **Draw Current Frame**:
    *   From **Logic**, drag `controls_if` with ELSE.
    *   **If** `frame` == 0:
        *   Draw `pac_open` bitmap at (`pac_x`, 28)
    *   **Else**:
        *   Draw `pac_closed` bitmap at (`pac_x`, 28)

8.  **Move Pac-Man**:
    *   From **Math**, calculate: `pac_x` = `pac_x` + 1
    *   **If** `pac_x` > 128: **Then**: `pac_x` = -8 (wrap to left edge)

9.  **Update Display**:
    *   From **Smart Display**, drag `pico_oled_show`.

10. **Frame Delay**:
    *   From **Time**, drag `pico_wait` -> 0.05 seconds.

### 8. Execution Flow
1.  **Start**: Initialize display, define two Pac-Man bitmaps.
2.  **Loop**: Clear, toggle frame every 10 iterations, draw bitmap, move right, wrap, update, wait.
3.  **Result**: Pac-Man moves right while mouth opens/closes.

### 9. Generated Code
```python
from machine import Pin, I2C
from ssd1306 import SSD1306_I2C
import time
import framebuf

# Initialize OLED
i2c = I2C(0, sda=Pin(0), scl=Pin(1), freq=400000)
oled = SSD1306_I2C(128, 64, i2c)

# Define Pac-Man bitmaps (8x8)
pac_open = bytearray([0x3C, 0x7E, 0xFE, 0xFF, 0xFC, 0xFE, 0x7E, 0x3C])
pac_closed = bytearray([0x3C, 0x7E, 0xFF, 0xFF, 0xFF, 0xFF, 0x7E, 0x3C])

# Create frame buffers
fb_open = framebuf.FrameBuffer(pac_open, 8, 8, framebuf.MONO_VLSB)
fb_closed = framebuf.FrameBuffer(pac_closed, 8, 8, framebuf.MONO_VLSB)

# Initialize variables
pac_x = 0
frame = 0
frame_counter = 0

# Main loop
while True:
    oled.fill(0)
    
    # Animate frame
    frame_counter += 1
    if frame_counter % 10 == 0:
        frame = 1 - frame
    
    # Draw current frame
    if frame == 0:
        oled.blit(fb_open, pac_x, 28)
    else:
        oled.blit(fb_closed, pac_x, 28)
    
    # Move Pac-Man
    pac_x += 1
    if pac_x > 128:
        pac_x = -8
    
    oled.show()
    time.sleep(0.05)
```

### 10. Common Mistakes
*   **Wrong Bitmap Format**: Ensure bitmap bytes match screen format (MONO_VLSB for SSD1306).
*   **Too Many Frames**: More than 3-4 frames requires significant memory.
*   **Animation Too Fast**: Toggle frame every frame makes mouth flicker - use counter.

*   **More Frames**: Add 3rd and 4th frame for smoother mouth animation.
*   **Direction Change**: Make Pac-Man reverse direction when hitting edge.
*   **Ghosts**: Add enemy sprites chasing Pac-Man with different movement patterns.
